# Club Pádel 04 · Estados del pipeline comercial

## Estados recomendados

1. No contactado
2. Contactado
3. Respondió
4. Interesado
5. Demo agendada
6. Demo realizada
7. Datos solicitados
8. Propuesta enviada
9. En negociación
10. Piloto aceptado
11. Perdido
12. Pausado

## Uso recomendado

Cada club debe tener siempre un único estado principal.

## Regla práctica

Después de cada contacto, actualizar:

- Estado.
- Último contacto.
- Próximo seguimiento.
- Objeción principal.
- Siguiente acción.
