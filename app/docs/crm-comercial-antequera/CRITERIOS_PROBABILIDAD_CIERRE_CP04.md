# Club Pádel 04 · Criterios de probabilidad de cierre comercial

## Objetivo

Definir una forma clara y práctica de valorar la probabilidad de cierre de cada club dentro del CRM comercial.

## 0%

Se usa cuando:

- El club todavía no ha sido contactado.
- No existe conversación iniciada.
- No hay información sobre su interés.

## 10%

Se usa cuando:

- Se ha localizado el club.
- Hay datos básicos del club.
- Aún no se ha enviado mensaje.

## 20%

Se usa cuando:

- Se ha enviado primer mensaje.
- No hay respuesta todavía.
- Se ha identificado una posible necesidad.

## 35%

Se usa cuando:

- El club responde.
- Hay una conversación inicial.
- Se detecta interés leve.
- Todavía no se ha enseñado la demo.

## 50%

Se usa cuando:

- El club acepta ver la demo.
- Hay interés real.
- La persona de contacto entiende el problema.
- Se puede enseñar PDF comercial y app visual.

## 65%

Se usa cuando:

- La demo ya se ha realizado.
- El club hace preguntas concretas.
- Pregunta por precio, implantación o mantenimiento.
- Se detecta una necesidad real.

## 75%

Se usa cuando:

- El club pide propuesta o condiciones.
- Se han recogido datos básicos.
- Existe posibilidad real de piloto.
- Hay una siguiente reunión o seguimiento claro.

## 85%

Se usa cuando:

- El club acepta revisar el Pack Fundador.
- Hay acuerdo verbal parcial.
- Solo faltan datos, fechas o confirmación interna.

## 95%

Se usa cuando:

- El club confirma intención de empezar.
- Solo falta formalizar condiciones, pago o calendario.
- Se prepara implantación controlada.

## 100%

Se usa solo cuando:

- El club acepta formalmente.
- Se pactan condiciones.
- Se define fecha de inicio.
- Se confirma el primer pago o acuerdo escrito.

## Regla importante

No marcar una oportunidad como 100% hasta tener confirmación clara del club.
