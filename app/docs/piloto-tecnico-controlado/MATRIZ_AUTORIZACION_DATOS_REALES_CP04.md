# Club Pádel 04 · Matriz de autorización antes de tocar datos reales

## Objetivo

Definir qué acciones necesitan autorización antes de usar datos o activar funciones reales.

| Acción | Puede hacerse en demo | Requiere autorización | Responsable recomendado |
|---|---:|---:|---|
| Mostrar app visual | Sí | No | Eduardo |
| Enviar PDF comercial | Sí | No | Eduardo |
| Simular reserva ficticia | Sí | No | Eduardo |
| Crear reserva real | No | Sí | Club + Eduardo |
| Cancelar reserva real | No | Sí | Club + Eduardo |
| Importar jugadores reales | No | Sí | Club |
| Usar teléfonos reales | No | Sí | Club |
| Usar emails reales | No | Sí | Club |
| Conectar Airtable real | No | Sí | Eduardo + club |
| Activar Make real | No | Sí | Eduardo |
| Activar WhatsApp Business real | No | Sí | Club + Eduardo |
| Activar pagos reales | No | Sí | Club + Eduardo |
| Conectar dominio definitivo | No | Sí | Eduardo + titular dominio |
| Modificar DNS | No | Sí | Titular dominio |
| Publicar producción comercial | No | Sí | Club + Eduardo |

## Regla general

Si una acción puede afectar a clientes reales, reservas reales, pagos reales, datos reales, comunicaciones reales o dominio real, no se ejecuta sin autorización previa.

## Recomendación

Durante el primer piloto usar siempre:

- Datos ficticios.
- Entorno de prueba.
- Preview seguro.
- Documentación firmada o aceptada antes de producción.
