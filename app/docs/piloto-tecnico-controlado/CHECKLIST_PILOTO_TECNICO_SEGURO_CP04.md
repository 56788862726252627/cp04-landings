# Club Pádel 04 · Checklist piloto técnico seguro

## Puede usarse en piloto

- App visual.
- PDF comercial.
- Demo guiada.
- Paquete maestro.
- Propuesta editable.
- Acuerdo simple piloto.
- Checklist de datos.
- Material comercial.
- Preview Cloudflare Pages.
- Explicación de funcionalidades previstas.

## No debe activarse todavía

- Pagos reales.
- Reservas reales.
- Cancelaciones reales.
- WhatsApp Business real.
- Webhooks reales con datos de cliente.
- Escrituras reales en Airtable de cliente.
- Dominio definitivo conectado.
- DNS modificado.
- Automatizaciones reales de cliente final.
- Correos automáticos a usuarios reales.
- Alta real de jugadores sin autorización.

## Condición para avanzar

Solo se podrá pasar a una producción real cuando:

1. El club confirme interés.
2. Se recopilen datos reales.
3. Se firme o acepte un acuerdo mínimo.
4. Se valide el alcance.
5. Se defina responsable del club.
6. Se configure un entorno separado.
7. Se pruebe primero con datos ficticios.
8. Se apruebe el checklist final.
