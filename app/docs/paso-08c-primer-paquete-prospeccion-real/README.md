# Paso 08C — Primer paquete de prospección real (sin envío)

Paquete completo para contactar al primer club real. **Ningún mensaje, email o llamada de este paquete se ha ejecutado** — es material listo para uso manual por el propietario del proyecto.

## Documentos de esta carpeta

- **`primer-club-checklist.md`** — cómo elegir a qué club contactar primero (cercanía/confianza, tamaño, herramientas actuales, problema probable, persona de contacto), qué NO prometer todavía, y cómo explicar el bloqueo técnico (Airtable 429) sin jerga.
- **`mensaje-whatsapp-primer-contacto.md`** — 5 versiones de mensaje de WhatsApp (muy corta, cercana, profesional, ahorro de tiempo, automatización), sin enlaces inventados.
- **`email-primer-contacto.md`** — 2 asuntos + 4 variantes de email (corto, formal, invitación a demo, seguimiento).
- **`guion-llamada-demo-15min.md`** — guion de apoyo para la llamada/demo, con preguntas de diagnóstico, qué mostrar, cómo cerrar el siguiente paso, objeciones frecuentes, y las respuestas honestas sobre Playtomic y sobre el estado técnico actual.
- **`ficha-prospeccion-club-template.md`** — plantilla para llevar el registro manual de cada club contactado (contacto, canal, problemas detectados, interés, siguiente paso, estado).

## Cómo usar este paquete sin enviar nada automáticamente

1. Usar `primer-club-checklist.md` para decidir a qué club escribir primero — nadie se contacta automáticamente desde aquí, es una decisión manual.
2. Elegir **una** versión de `mensaje-whatsapp-primer-contacto.md` o `email-primer-contacto.md` según el canal y el perfil del contacto, y copiarla manualmente en WhatsApp/email para enviarla uno mismo.
3. Si consiguen una llamada, apoyarse en `guion-llamada-demo-15min.md` durante la conversación — no leerlo literalmente, usarlo como estructura y banco de respuestas ante objeciones.
4. Rellenar una copia de `ficha-prospeccion-club-template.md` por cada club contactado, para llevar seguimiento manual.
5. Mantener siempre el lenguaje honesto ya establecido en `app/docs/paso-08a-agencia-ia-oferta-comercial/limites-y-riesgos-actuales.md`: demo funcional avanzada, validación real end-to-end pendiente por el bloqueo externo de Airtable — nunca prometer producción real completa antes de tiempo.

Este paquete no automatiza ni dispara ningún envío por sí mismo: todo el contacto real con clubes lo ejecuta una persona, copiando y personalizando manualmente el contenido de estos documentos.
