# Mini-CRM de prospección — plantilla (Paso 08D)

Tabla manual para llevar el seguimiento de varios clubes a la vez. Complementa la ficha individual de `app/docs/paso-08c-primer-paquete-prospeccion-real/ficha-prospeccion-club-template.md` (una ficha detallada por club) con una vista de conjunto en formato tabla, útil cuando se contacta a varios clubes en paralelo.

Copiar esta tabla a una hoja de cálculo (Google Sheets/Excel) para uso real — el Markdown de abajo es solo la plantilla de columnas.

## Valores sugeridos por columna

- **Estado:** sin contactar / contactado sin respuesta / en conversación / demo agendada / demo realizada / piloto en negociación / descartado.
- **Respuesta:** positiva / neutra / negativa / sin respuesta.
- **Interés:** bajo / medio / alto.
- **Objeción principal:** usar las categorías de `respuestas-objeciones-clubes.md` (Playtomic, precio, estado técnico, pagos, WhatsApp, sustituye personal, garantías, prueba, datos) o "ninguna" si no ha surgido.
- **Siguiente acción:** enviar seguimiento día X / proponer llamada / enviar diagnóstico / agendar demo / cerrar contacto.
- **Prioridad:** A / B / C, según `lista-priorizacion-clubes.md`.

## Cómo usar

1. Añadir una fila por cada club contactado (no mezclar varios clubes en una fila).
2. Actualizar la fila cada vez que haya una interacción nueva (respuesta, llamada, demo).
3. Revisar semanalmente la columna "Fecha próxima acción" para no dejar ningún club sin seguimiento.
4. Nunca marcar "piloto en negociación" o un estado más avanzado sin que exista una conversación real que lo respalde — esta tabla es un reflejo honesto del estado real, no un objetivo a inflar.
