# Paso 08D — Segundo paquete de prospección real (sin envío)

Amplía el paquete del Paso 08C para poder gestionar la prospección de **varios** clubes a la vez de forma ordenada, con priorización, seguimiento a 7 días, objeciones adicionales y checklist de demo en vivo. **Ningún mensaje, email o llamada de este paquete se ha ejecutado.**

## Documentos de esta carpeta

- **`lista-priorizacion-clubes.md`** — sistema de puntuación (cercanía, tamaño, herramientas actuales, dolor visible, probabilidad de respuesta, potencial de pago) para clasificar clubes en Prioridad A/B/C, y qué clubes no contactar todavía.
- **`secuencia-manual-7-dias.md`** — cadencia de seguimiento manual (día 1, 2, 3, 5, 7) con mensajes de WhatsApp y email para cada punto, a usar solo mientras el club no responda.
- **`respuestas-objeciones-clubes.md`** — 10 objeciones adicionales con respuestas honestas (Playtomic, cambio de sistema, precio, estado en producción, pagos, WhatsApp, sustitución de personal, garantías, prueba, datos necesarios).
- **`mini-crm-prospeccion-template.md`** — tabla manual para llevar el seguimiento de varios clubes en paralelo (complementa la ficha individual del Paso 08C).
- **`mensaje-demo-confirmada.md`** — mensajes para cuando un club ya aceptó la demo (confirmación, recordatorio 24h/2h antes, mensaje posterior).
- **`checklist-demo-en-vivo.md`** — checklist operativo para hacer la demo de forma segura (qué abrir, qué enseñar/no enseñar, cómo explicar Airtable 429 y los 40/50 flujos, criterios de demo exitosa).

## Cómo usar este paquete junto al 08C

1. Usar `lista-priorizacion-clubes.md` para ordenar la lista completa de clubes candidatos (el Paso 08C solo cubría cómo elegir el primer club individual).
2. Para cada club, seguir `app/docs/paso-08c-primer-paquete-prospeccion-real/mensaje-whatsapp-primer-contacto.md` o `email-primer-contacto.md` para el primer contacto, y si no hay respuesta, continuar con `secuencia-manual-7-dias.md` de este paquete.
3. Registrar cada club en `mini-crm-prospeccion-template.md` (vista de conjunto) y opcionalmente también en la ficha individual del 08C si se quiere más detalle por club.
4. Ante cualquier objeción, consultar primero `app/docs/paso-08c-primer-paquete-prospeccion-real/guion-llamada-demo-15min.md` y, si no está cubierta ahí, `respuestas-objeciones-clubes.md` de este paquete.
5. En cuanto un club acepte la demo, usar `mensaje-demo-confirmada.md` para confirmarla y recordarla, y `checklist-demo-en-vivo.md` justo antes de empezarla.
6. Mantener siempre el lenguaje honesto ya establecido: demo funcional avanzada, validación real end-to-end pendiente por el bloqueo externo de Airtable — ningún documento de este paquete autoriza a decir lo contrario.

Ningún documento de esta carpeta envía, programa ni dispara nada automáticamente: todo el contacto real lo ejecuta una persona, copiando y personalizando manualmente cada mensaje.
