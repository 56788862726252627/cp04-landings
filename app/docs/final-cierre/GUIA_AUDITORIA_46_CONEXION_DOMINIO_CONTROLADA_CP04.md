# Club Pádel 04 · Guía Auditoría 46 · Conexión dominio controlada

## Objetivo

Preparar la conexión controlada del dominio definitivo en Cloudflare Pages, con revisión manual previa y sin activar pagos reales.

## Punto de partida

Preview actual:

https://c4403e7d.club-padel-04.pages.dev

## Antes de conectar

Confirmar manualmente:

1. Dominio definitivo exacto.
2. Cuenta Cloudflare correcta.
3. Zona DNS correcta.
4. Proyecto Pages correcto.
5. Custom domain correcto.
6. SSL/TLS activo.
7. Redirección www/no-www decidida.
8. URL preview guardada como fallback.
9. ZIP final guardado.
10. Plan rollback disponible.

## No activar todavía

- Pagos reales.
- Producción comercial completa.
- Automatizaciones destructivas.
- Cancelaciones reales sin validación.
- Webhooks sensibles expuestos.

## Resultado esperado

Conectar dominio definitivo de forma controlada solo cuando se confirme manualmente.
