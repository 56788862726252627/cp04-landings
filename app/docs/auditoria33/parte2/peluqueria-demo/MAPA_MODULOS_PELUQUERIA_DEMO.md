# MAPA DE MÓDULOS · Peluquería Demo

## Módulos base

- Inicio
- Citas
- Clientes
- Servicios
- Profesionales
- Perfil
- Administración
- Soporte

## Módulos recomendados para primera versión

### Inicio

Debe mostrar:

- citas de hoy
- citas pendientes
- clientes activos
- ingresos estimados
- servicios más reservados
- próximos huecos libres

### Citas

Debe permitir:

- crear cita
- cancelar cita
- cambiar hora
- seleccionar servicio
- seleccionar profesional
- seleccionar fecha y hora
- enviar confirmación

### Clientes

Debe permitir:

- consultar cliente
- ver historial
- datos básicos
- preferencias
- notas internas

### Servicios

Debe incluir:

- nombre del servicio
- duración
- precio
- profesional compatible
- disponibilidad

### Profesionales

Debe incluir:

- nombre
- especialidad
- horario
- servicios asociados
- disponibilidad

### Admin

Debe incluir:

- métricas
- agenda
- clientes
- servicios
- profesionales
- configuración
