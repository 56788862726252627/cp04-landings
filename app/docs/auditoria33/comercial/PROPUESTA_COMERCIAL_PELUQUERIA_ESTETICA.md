# PROPUESTA COMERCIAL · SaaS para Peluquería / Estética

## Qué es

Sistema digital para peluquerías, barberías y centros de estética que permite gestionar citas, clientes, servicios, profesionales, recordatorios y automatizaciones.

## Problemas que resuelve

- citas por WhatsApp desordenadas
- olvidos de clientes
- huecos libres sin ocupar
- falta de seguimiento
- poca automatización
- dificultad para gestionar profesionales
- ausencia de recordatorios
- poca fidelización

## Beneficios

Para el negocio:

- agenda más ordenada
- menos tiempo respondiendo mensajes
- mejor imagen profesional
- recordatorios automáticos
- seguimiento de clientes
- promociones más fáciles
- posibilidad de mantenimiento mensual

Para el cliente:

- citas más claras
- recordatorios
- mejor experiencia
- comunicación profesional
