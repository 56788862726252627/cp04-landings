# DEMO GUIADA · Club Pádel 04

## Objetivo

Tener un guion claro para presentar Club Pádel 04 a un club deportivo.

---

## 1. Inicio de la demo

Mensaje inicial:

Club Pádel 04 es una solución digital para ayudar a clubes deportivos a gestionar reservas, socios, comunicación y automatizaciones desde una app moderna y personalizada.”

---

## 2. Pantalla de inicio

Mostrar:

- estética premium
- identidad visual

- acceso rápido a reservas, torneos y procesos

Explicar:

Esta pantalla permite al club tener una visión rápida del estado operativo.”

---

## 3. Reservas

Mostrar:

- módulo de reservas
- disponibilidad
- flujo de reserva
- posibilidad de automatizar confirmaciones

Explicar:

El objetivo es reducir reservas manuales por WhatsApp o llamadas.”

## 4. Perfil y ajustes

Mostrar:

- perfil de usuario
- datos deportivos
- sesión activa
- autenticación

- ajustes

Explicar:

Cada usuario puede tener su perfil, y el club puede trabajar con roles y permisos.”

## 5. Roles

Explicar:

El sistema puede separar:

- jugador/cliente
- recepción/staff
- administrador
- soporte técnico

Beneficio:

Cada persona ve lo que necesita, sin mezclar permisos.”

La app no funciona sola: se conecta con automatizaciones para ahorrar trabajo al club.”

## 8. Escalabilidad
