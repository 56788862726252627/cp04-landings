# Club Pádel 04 · Modo presentación

## Objetivo

Tener un orden claro para enseñar el proyecto sin entrar en carpetas técnicas ni documentación excesiva.

## Orden recomendado

### 1. PDF corto premium

Usar como primer impacto visual.

Mensaje:

"Este es un resumen corto para entender la propuesta en pocos minutos."

### 2. App visual

Mostrar pantalla inicial y roles.

Mensaje:

"La app está pensada para que jugador, recepción, administración y soporte tengan áreas diferenciadas."

### 3. Reserva funcional

Mostrar el módulo de reservar.

Mensaje:

"El flujo de reserva ya funciona técnicamente: app, Make y correo."

### 4. Paneles internos

Mostrar staff, administrador, ranking, torneos e incidencias.

Mensaje:

"La idea no es solo reservar, sino dar más control operativo al club."

### 5. Propuesta económica

Mostrar packs.

Mensaje:

"Mi recomendación para una primera fase sería el Pack Fundador."

### 6. Próximo paso

Mensaje:

"Si encaja, el siguiente paso sería recoger datos básicos del club y plantear una prueba controlada."
