# Club Pádel 04 · Checklist antes de enviar a un club

## Material listo

- PDF corto premium preparado.
- PDF comercial completo preparado.
- Mensaje WhatsApp preparado.
- Email preparado.
- Guion de llamada preparado.
- Guion de demo preparado.
- Packs de precio claros.
- Objeciones y respuestas preparadas.
- Prueba de funcionamiento preparada.

## Antes de contactar

- Revisar el nombre del club.
- Comprobar quién es el responsable.
- Preparar mensaje personalizado.
- Tener abierta la app.
- Tener localizado el PDF corto.
- Tener localizado el PDF completo.
- Tener clara la oferta.
- Tener claro el siguiente paso: demo de 10-15 minutos.

## Durante el contacto

- Ser breve.
- No saturar con demasiada información.
- No prometer producción real inmediata.
- Explicar que es una demo/piloto controlado.
- Proponer reunión o demo.

## Después del contacto

- Anotar respuesta.
- Guardar fecha.
- Preparar seguimiento.
- Enviar PDF si hay interés.
- Proponer demo.
