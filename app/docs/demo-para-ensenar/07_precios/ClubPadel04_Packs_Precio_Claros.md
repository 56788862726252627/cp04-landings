# Club Pádel 04 · Packs de precio claros

## Pack Inicio

### Precio

990 € instalación inicial  
+ 149 €/mes mantenimiento

### Para quién

Club pequeño, validación inicial o primera demo operativa sencilla.

### Incluye

- App visual básica.
- Módulo de reservas.
- Acceso jugador.
- Área básica de administración.
- Configuración inicial simple.
- Soporte básico.

### No incluye

- Automatizaciones avanzadas.
- Pagos reales.
- WhatsApp Business real.
- Personalización profunda.
- Soporte prioritario.
