# CRITERIOS · No crear más verticales todavía

## Motivo

La Agencia IA ya tiene suficientes verticales conceptuales para validar mercado.

Crear más verticales ahora puede generar:

- dispersión
- duplicación
- falsa sensación de avance
- demasiada documentación sin ventas
- falta de foco comercial

## Verticales suficientes para validar

- Clubes deportivos / pádel
- Peluquería / estética
- Fisioterapia
- Veterinaria

## Condición para crear un nuevo vertical

Solo crear clínica dental, abogados, fertilidad u otro vertical cuando se cumpla al menos una de estas condiciones:

- Se hayan contactado 18 negocios mínimos.
- Haya al menos 3 respuestas reales.
- Haya al menos 1 demo realizada.
- Un cliente potencial pida explícitamente otro sector.
- Se detecte una oportunidad clara con presupuesto.
- El producto base Club Pádel 04 esté listo para demo comercial estable.

## Regla principal

Primero validar mercado.  
Después crear más verticales.
