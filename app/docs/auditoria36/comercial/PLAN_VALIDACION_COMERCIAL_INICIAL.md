# PLAN VALIDACIÓN COMERCIAL INICIAL · Agencia IA

## Objetivo

Validar interés real antes de seguir creando más verticales.

## Contactos mínimos

| Vertical | Contactos mínimos |
|---|---:|
| Clubes deportivos | 5 |
| Fisioterapia | 5 |
| Peluquería / estética | 5 |
| Veterinaria | 3 |

## Qué preguntar

- ¿Cómo gestionáis ahora las citas/reservas?
- ¿Qué parte os consume más tiempo?
- ¿Qué problema os gustaría automatizar primero?
- ¿Usáis alguna herramienta actualmente?
- ¿Qué os falta en esa herramienta?
- ¿Pagaríais por una app personalizada con automatizaciones?
- ¿Qué precio mensual os parecería razonable?
- ¿Queréis ver una demo?

## Qué medir

- respuesta positiva
- interés en demo
- dolor real
- urgencia
- capacidad de pago
- objeciones
- funcionalidades imprescindibles

## Señales de buen cliente

- responde rápido
- reconoce problema
- ya paga por herramientas
- tiene muchas citas/reservas
- quiere ahorrar tiempo
- tiene equipo o volumen
- acepta una demo

## Señales de mal cliente inicial

- solo quiere algo gratis
- no tiene volumen
- no sabe qué problema tiene
- pide demasiadas cosas sin presupuesto
- quiere WhatsApp/pagos/IA avanzada desde el primer día sin pagar
