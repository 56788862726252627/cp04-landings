# RANKING PRIORIDAD COMERCIAL · Agencia IA

## Objetivo

Definir qué vender primero para avanzar rápido sin dispersarse.

## Ranking recomendado

### 1. Club Pádel 04 / clubes deportivos

Prioridad: máxima.

Motivo:

- producto base ya trabajado
- más coherente con el origen del proyecto
- se puede enseñar como caso principal
- permite crear prueba comercial real
- no requiere inventar otro producto desde cero

Acción recomendada:

Contactar clubes de pádel cercanos o conocidos y ofrecer demo.

### 2. Fisioterapia

Prioridad: alta.

Motivo:

- mayor margen mensual
- agenda, citas, profesionales y bonos encajan muy bien
- cliente profesional con más capacidad de pago que peluquería
- conecta con deporte/salud

Acción recomendada:

Preparar lista de 10 clínicas de fisioterapia cercanas y contactar con mensaje breve.

### 3. Peluquería / estética

Prioridad: media-alta.

Motivo:

- venta más fácil
- bajo riesgo
- sirve para validar rápido
- menor ticket, pero buen entrenamiento comercial

Acción recomendada:

Usar como vertical de prueba para conseguir primeras reuniones.

### 4. Veterinaria

Prioridad: media.

Motivo:

- buen potencial
- recordatorios muy vendibles
- pero no debe distraer antes de validar pádel/fisio/peluquería

Acción recomendada:

Dejar preparada para segunda oleada comercial.

## Decisión final

No crear nuevos verticales hasta hacer validación comercial mínima con:

- 5 clubes deportivos
- 5 fisioterapias
- 5 peluquerías/estética
- 3 veterinarias
