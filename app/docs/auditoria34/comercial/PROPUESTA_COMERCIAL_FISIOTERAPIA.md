# PROPUESTA COMERCIAL · SaaS para Fisioterapia

## Qué es

Sistema digital para clínicas de fisioterapia y centros de rehabilitación que permite gestionar citas, pacientes, profesionales, tratamientos, bonos, recordatorios y automatizaciones.

## Problemas que resuelve

- citas gestionadas manualmente
- demasiados mensajes repetitivos
- olvidos de pacientes
- huecos libres sin ocupar
- poco seguimiento tras la sesión
- dificultad para controlar bonos
- agenda poco centralizada
- falta de recordatorios automáticos
- baja automatización comercial

## Beneficios

Para la clínica:

- agenda más ordenada
- menos trabajo administrativo
- mayor control de sesiones
- recordatorios automáticos
- seguimiento básico del paciente
- mejor experiencia
- posibilidad de vender bonos
- mantenimiento mensual justificable

Para el paciente:

- citas más claras
- recordatorios
- mejor seguimiento
- comunicación más profesional
- experiencia más ordenada
