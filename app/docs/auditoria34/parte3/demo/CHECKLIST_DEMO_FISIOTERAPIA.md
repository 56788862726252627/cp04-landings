## Antes de enseñar la demo

- [ ] App base carga correctamente.
- [ ] No hay pantalla negra.
- [ ] No hay datos sensibles visibles.
- [ ] Se explica que es demo conceptual.
- [ ] No se promete WhatsApp si no está configurado.
- [ ] No se promete pago online si no está integrado.
- [ ] No se prometen diagnósticos con IA.
- [ ] No se prometen recomendaciones médicas automáticas.
- [ ] Se explica que el enfoque inicial es agenda, citas, bonos, recordatorios y gestión.

## Orden de presentación

1. Problema actual.
2. Agenda/citas.
3. Pacientes.
4. Tratamientos.
5. Profesionales.
6. Bonos.
7. Recordatorios.
8. Automatizaciones.
9. Paquetes.
10. Próximo paso.

## Preguntas a la clínica

- ¿Cómo gestionáis ahora las citas?
- ¿Cuántas citas tenéis por semana?
- ¿Cuántos fisioterapeutas trabajan?
- ¿Vendéis bonos de sesiones?
- ¿Tenéis muchos cambios o cancelaciones?
- ¿Os interesan recordatorios automáticos?
- ¿Queréis avisos de bonos bajos?
- ¿Qué parte administrativa os quita más tiempo?
- ¿Qué presupuesto mensual tendría sentido si el sistema os ahorra tiempo?
