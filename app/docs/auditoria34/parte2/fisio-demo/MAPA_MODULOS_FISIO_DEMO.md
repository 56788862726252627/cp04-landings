# MAPA DE MÓDULOS · Clínica Fisio Demo

## Módulos base

- Inicio
- Citas
- Pacientes
- Servicios / tratamientos
- Profesionales
- Bonos / sesiones
- Perfil
- Administración
- Automatizaciones
- Soporte

## Módulos recomendados para primera versión

### Inicio

Debe mostrar:

- citas de hoy
- pacientes activos
- sesiones pendientes
- bonos activos
- ingresos estimados
- ocupación por profesional
- próximos huecos libres

### Citas

Debe permitir:

- crear cita
- seleccionar tratamiento
- seleccionar fisioterapeuta
- seleccionar fecha y hora
- confirmar
- cancelar
- reprogramar

### Pacientes

Debe permitir:

- datos básicos
- historial administrativo
- citas próximas
- bonos activos
- notas internas no sensibles
- preferencias de contacto

### Servicios / tratamientos

Debe incluir:

- nombre
- duración
- precio
- profesional compatible
- disponibilidad

### Profesionales

Debe incluir:

- nombre
- especialidad
- horario
- servicios asociados
- disponibilidad

### Bonos / sesiones

Debe incluir:

- tipo de bono
- sesiones compradas
- sesiones consumidas
- sesiones restantes
- aviso de bono bajo

### Admin

Debe incluir:

- agenda
- pacientes
- profesionales
- servicios
- bonos
- métricas
- automatizaciones
- configuración

## Límites importantes

No incluir en esta fase:

- diagnóstico automático
- recomendaciones médicas automáticas
- gestión de historial clínico sensible
- tratamiento de datos sanitarios reales
