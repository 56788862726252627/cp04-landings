# Club Pádel 04 · Checklist posterior a reunión Antequera

## Justo después de la reunión

- [ ] Anotar nombre del contacto.
- [ ] Anotar cargo.
- [ ] Anotar número de pistas.
- [ ] Anotar fecha prevista de apertura.
- [ ] Anotar sistema actual previsto para reservas.
- [ ] Anotar si tienen interés en torneos/ranking.
- [ ] Anotar dudas principales.
- [ ] Anotar objeciones de precio.
- [ ] Anotar siguiente paso acordado.

## Si hay interés

- [ ] Enviar resumen por WhatsApp/email.
- [ ] Enviar propuesta breve.
- [ ] Proponer segunda reunión.
- [ ] Pedir datos básicos del club.
- [ ] Preparar adaptación visual si procede.
- [ ] Definir fecha de implantación.

## Si no hay respuesta

- [ ] Seguimiento a los 2 días.
- [ ] Segundo seguimiento a los 7 días.
- [ ] No insistir de forma pesada.
- [ ] Mantener contacto para apertura.

## Datos mínimos para implantación

- [ ] Nombre comercial del club.
- [ ] Logo.
- [ ] Colores.
- [ ] Número de pistas.
- [ ] Nombres de pistas.
- [ ] Horarios.
- [ ] Precios.
- [ ] Normas de cancelación.
- [ ] Empleados.
- [ ] Email de administración.
- [ ] Teléfono de contacto.
