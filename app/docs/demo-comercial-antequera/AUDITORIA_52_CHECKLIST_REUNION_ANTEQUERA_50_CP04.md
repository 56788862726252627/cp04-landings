# Club Pádel 04 · Checklist reunión Antequera

## Antes de la reunión

- [ ] Abrir app local o preview.
- [ ] Comprobar pantalla inicial.
- [ ] Comprobar acceso por roles.
- [ ] Comprobar jugador.
- [ ] Comprobar staff.
- [ ] Comprobar admin.
- [ ] Comprobar torneos.
- [ ] Comprobar ranking.
- [ ] No mostrar terminal.
- [ ] No mostrar código.
- [ ] No mostrar Make.
- [ ] No mostrar Airtable.
- [ ] No mostrar Cloudflare.
- [ ] Tener precio claro.
- [ ] Tener propuesta de entrada.

## Durante la reunión

- [ ] Empezar por problema.
- [ ] Mostrar pantalla inicial.
- [ ] Destacar Torcal / Antequera.
- [ ] Enseñar jugador.
- [ ] Enseñar reservas.
- [ ] Enseñar staff.
- [ ] Enseñar admin.
- [ ] Enseñar torneos/ranking.
- [ ] Explicar automatizaciones sin enseñar arquitectura.
- [ ] Presentar precio.
- [ ] Preguntar necesidades.
- [ ] Proponer siguiente paso.

## Después de la reunión

- [ ] Enviar resumen.
- [ ] Enviar propuesta.
- [ ] Pedir fecha de decisión.
- [ ] Pedir datos básicos del club si hay interés.
- [ ] Agendar segunda reunión.
