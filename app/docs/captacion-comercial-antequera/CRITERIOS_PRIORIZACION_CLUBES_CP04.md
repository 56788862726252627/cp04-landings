# Club Pádel 04 · Criterios para priorizar clubes

## Prioridad alta

Un club será prioridad alta si cumple varias de estas condiciones:

- Tiene varias pistas.
- Tiene actividad recurrente.
- Usa WhatsApp o llamadas para reservas.
- Tiene torneos o ranking.
- Tiene escuela.
- Tiene recepción o personal administrativo.
- Quiere mejorar imagen digital.
- Tiene problemas de organización.
- Puede tomar decisiones rápido.
- Está en Antequera o zona cercana.

## Prioridad media

- Tiene pocas pistas pero actividad constante.
- Puede necesitar una app sencilla.
- No tiene urgencia inmediata, pero puede interesarle una demo.
- Puede ser buen caso piloto si el trato es cercano.

## Prioridad baja

- No tiene actividad suficiente.
- No quiere digitalizar.
- Ya tiene una solución cerrada.
- No tiene persona clara de decisión.
- Solo quiere información sin intención real.

## Recomendación comercial

Empezar por clubes donde la propuesta pueda entenderse como una mejora gradual, no como un cambio brusco.

Mensaje clave:

No se trata de sustituir todo de golpe, sino de ordenar reservas, jugadores, comunicación y administración en una primera fase controlada.
