# Club Pádel 04 · Mensaje corto de presentación

## Versión presencial o llamada

Hola, soy Eduardo Rodríguez. Estoy preparando Club Pádel 04, un sistema digital para ayudar a clubes de pádel de Antequera a gestionar reservas, jugadores, staff, torneos, ranking y administración desde una app propia.

La idea no es cambiarlo todo de golpe, sino enseñar una demo sencilla de 10-15 minutos para ver si puede encajar con vuestro club y reducir gestión manual, llamadas, WhatsApp repetitivo y errores de organización.

Tengo una propuesta visual preparada y un Pack Fundador para una primera implantación controlada.
