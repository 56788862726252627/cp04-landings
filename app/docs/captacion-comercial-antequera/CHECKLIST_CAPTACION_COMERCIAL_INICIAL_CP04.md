# Club Pádel 04 · Checklist captación comercial inicial

## Antes de contactar

- Revisar PDF comercial premium.
- Confirmar que el PDF abre correctamente.
- Confirmar que la app visual abre correctamente.
- Tener preparado el guion de demo.
- Tener preparado el Pack Fundador.
- Tener claro el precio recomendado.
- Tener claros los límites del servicio.
- Tener preparadas respuestas a objeciones.
- Tener preparada una frase breve de presentación.
- Tener preparado un mensaje de WhatsApp.
- Tener preparado un email corto.
- Tener preparado un guion de llamada.
- Tener preparado un checklist de datos del club.

## Durante el contacto

- Presentarse de forma profesional.
- Explicar el problema de forma sencilla.
- Explicar el beneficio principal.
- No entrar en demasiados detalles técnicos.
- Proponer una demo de 10-15 minutos.
- Preguntar quién toma la decisión.
- Preguntar si gestionan reservas por WhatsApp, llamadas, Excel u otra herramienta.
- Detectar si hay interés real.
- No presionar.
- Dejar el PDF comercial como apoyo.

## Después del contacto

- Apuntar nombre del club.
- Apuntar persona de contacto.
- Apuntar cargo.
- Apuntar teléfono/email.
- Apuntar interés detectado.
- Apuntar objeciones.
- Apuntar próxima acción.
- Enviar PDF si procede.
- Agendar demo si procede.
