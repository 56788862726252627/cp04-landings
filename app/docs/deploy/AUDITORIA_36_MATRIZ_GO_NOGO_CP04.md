# Club Pádel 04 · Matriz GO / NO-GO

## GO para preview controlado

- App visual premium.
- Build correcto.
- dist listo.
- Galería optimizada.
- Centro técnico visible.
- Admin visible.
- Worker preparado.
- Sin deploy real todavía.
- Checkpoints completos.

## NO-GO para producción comercial final

- Falta dominio definitivo.
- Falta autenticación real.
- Falta conexión completa de secrets reales.
- Falta validar pagos reales.
- Falta validar cancelaciones reales.
- Falta RGPD completo.
- Falta monitorización real.
- Falta prueba final multiusuario.
- Falta protección real de roles.

## Recomendación

Publicar solo como preview/demo controlada hasta completar backend real, credenciales y pruebas finales.
