# DECISION GATE · P1-01

Antes de modificar código deben quedar confirmados:

- componente real que renderiza el acceso
- origen real del fondo
- relación del detector con la selección de rol
- reglas de posicionamiento
- comportamiento responsive
- activo visual utilizado realmente

## Prohibido todavía

- cambiar autenticación
- cambiar permisos
- cambiar IDs de rol
- cambiar lógica de login
- eliminar detectores
- sustituir imágenes sin validar su uso
- modificar código ajeno a P1-01

## Cambio permitido posteriormente

Solo cambios visuales mínimos y reversibles:

- composición
- encuadre
- posición
- contraste
- overlay
- ancho o altura visual del selector
- responsive

sin alterar comportamiento funcional.
