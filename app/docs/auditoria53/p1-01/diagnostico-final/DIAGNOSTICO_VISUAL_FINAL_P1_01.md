# DIAGNÓSTICO VISUAL FINAL · P1-01 Inicio Antequera

## Objetivo

Determinar el cambio mínimo necesario para convertir la pantalla de inicio en un activo visual comercial premium.

## Elementos inspeccionados

- componente de acceso
- selector de roles
- fondos disponibles
- detector de fondo por rol
- responsive
- referencias directas a activos
- composición actual

## Condición de avance

No modificar autenticación.

No modificar:

- IDs de rol
- contraseñas
- permisos
- funciones de login
- validación
- navegación
- detector de permisos

## Cambios visuales potenciales

Los únicos cambios permitidos para esta fase son:

- `background-position`
- `background-size`
- overlay
- gradiente
- contraste
- ancho visual del selector
- altura visual
- separación entre elementos
- posición de la tarjeta
- responsive
- espaciado

## Decisión pendiente

La decisión concreta se tomará únicamente después de confirmar:

1. fondo real de la pantalla inicial
2. origen del selector
3. reglas responsive activas
4. interacción del detector de fondo
5. si el Torcal queda oculto por la tarjeta
