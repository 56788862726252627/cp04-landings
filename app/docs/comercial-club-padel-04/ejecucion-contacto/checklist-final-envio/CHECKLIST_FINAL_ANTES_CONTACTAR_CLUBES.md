# CHECKLIST FINAL ANTES DE CONTACTAR CLUBES

## Antes de enviar cada mensaje

- [ ] He abierto el canal real del club.
- [ ] He comprobado que la cuenta o web parece oficial.
- [ ] He comprobado actividad reciente.
- [ ] He elegido el mensaje correcto.
- [ ] He eliminado promesas no verificadas.
- [ ] He preparado el registro de envío.
- [ ] Sé la fecha y hora de envío.
- [ ] No voy a enviar propuesta completa de primeras.
- [ ] No voy a prometer WhatsApp real.
- [ ] No voy a prometer pagos reales.
- [ ] Voy a pedir solo una demo de 10 minutos.

## Después de enviar

- [ ] Registrar fecha.
- [ ] Registrar hora.
- [ ] Registrar canal.
- [ ] Registrar mensaje usado.
- [ ] Esperar 48-72 horas antes de seguimiento.
- [ ] Registrar respuesta si llega.
- [ ] Registrar objeción si aparece.

## Regla principal

Una conversación real vale más que seguir creando documentación.
