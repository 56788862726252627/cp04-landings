# CHECKLIST VERIFICACIÓN CANAL · Clubes objetivo

## Objetivo

Verificar manualmente el canal correcto antes de contactar a cada club para evitar enviar mensajes a cuentas equivocadas, inactivas o no oficiales.

## Antes de contactar cada club

- [ ] Confirmar nombre real del club.
- [ ] Confirmar ciudad.
- [ ] Confirmar que sigue activo.
- [ ] Confirmar que ofrece pádel o actividad deportiva compatible.
- [ ] Confirmar canal oficial.
- [ ] Confirmar si el canal es Instagram, WhatsApp, teléfono, email o web.
- [ ] Confirmar si hay persona responsable visible.
- [ ] Confirmar que el mensaje elegido encaja.
- [ ] Confirmar que no se prometen pagos reales.
- [ ] Confirmar que no se promete WhatsApp real.
- [ ] Confirmar que se pide solo demo breve de 10 minutos.
- [ ] Registrar fecha de verificación.
