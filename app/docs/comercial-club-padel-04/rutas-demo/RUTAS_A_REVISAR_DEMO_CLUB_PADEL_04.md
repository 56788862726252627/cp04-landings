# RUTAS A REVISAR · Demo Club Pádel 04

## Objetivo

Tener una lista clara de rutas o vistas que deben revisarse antes de enseñar la demo.

## Ruta principal local

- http://localhost:5173/

## Rutas o variantes recientes vistas

- http://localhost:5173/?v=auditoria29-idioma-negro-borde-verde
- http://localhost:5173/?v=auditoria29-js-final-perfil-idiomas-validacion

## Regla

Las rutas con parámetros antiguos solo deben usarse para comprobar versiones si siguen funcionando.  
Para enseñar a un cliente se recomienda usar la ruta estable más limpia posible.

## Vistas a revisar

### 1. Inicio

Comprobar:

- carga inicial
- fondo
- título
- botones principales
- tarjetas
- legibilidad

### 2. Sidebar

Comprobar:

- módulos visibles
- perfil y ajustes
- cerrar sesión
- idioma
- modo seguro
- no hay parpadeos extraños

### 3. Reservas

Comprobar:

- flujo comprensible
- textos claros
- botones visibles
- no prometer pago real

### 4. Perfil

Comprobar:

- textos legibles
- fondo correcto
- permisos claros
- ajustes básicos entendibles

### 5. Administración

Comprobar:

- dashboard o métricas
- reservas del día
- usuarios o gestión
- explicación comercial clara

### 6. Soporte

Comprobar:

- no mostrar errores técnicos
- explicar que soporte es parte del mantenimiento

## Rutas no recomendadas para demo comercial

- rutas rotas
- rutas con pantalla negra
- rutas con parámetros de auditoría antiguos si causan confusión
- rutas que muestren terminal o contenido interno
