# CAPTURAS NECESARIAS · Demo Club Pádel 04

## Objetivo

Definir qué capturas se necesitan para preparar una demo comercial y una futura propuesta visual.

## Capturas mínimas

- [ ] Pantalla inicial.
- [ ] Sidebar abierto.
- [ ] Módulo reservas.
- [ ] Perfil y ajustes.
- [ ] Selector de idioma, si se muestra.
- [ ] Panel administrador.
- [ ] Vista de reservas del día.
- [ ] Vista de métricas.
- [ ] Vista soporte.
- [ ] Vista móvil/tablet si aplica.

## Capturas para propuesta comercial

- [ ] Imagen general de la app.
- [ ] Flujo de reserva.
- [ ] Panel de administración.
- [ ] Módulo de perfil.
- [ ] Ejemplo visual de automatizaciones.
- [ ] Captura sin errores visuales.
- [ ] Captura con identidad visual del Torcal/Antequera.

## Reglas

- No incluir tokens.
- No incluir credenciales.
- No incluir datos reales privados.
- No incluir marcas de apps competidoras.
- No incluir terminal.
- No incluir Make o Airtable con credenciales.
