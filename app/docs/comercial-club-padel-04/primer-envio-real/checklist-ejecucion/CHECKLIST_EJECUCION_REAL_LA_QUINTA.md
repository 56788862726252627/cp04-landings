# CHECKLIST EJECUCIÓN REAL · La Quinta

## Objetivo

Ejecutar el primer envío real de Club Pádel 04 de forma controlada.

## Antes de enviar

- [ ] Abrir Instagram.
- [ ] Buscar @laquintaantequera.
- [ ] Confirmar que parece cuenta oficial.
- [ ] Confirmar relación con La Quinta / Antequera.
- [ ] Confirmar actividad reciente.
- [ ] Confirmar que permite enviar DM.
- [ ] Abrir registro post envío.
- [ ] Copiar mensaje definitivo.
- [ ] Revisar que no promete pagos reales.
- [ ] Revisar que no promete WhatsApp real.
- [ ] Revisar que solo propone demo breve.

## Envío

- [ ] Enviar mensaje una sola vez.
- [ ] No adjuntar PDF.
- [ ] No añadir explicación larga.
- [ ] No hablar de precio salvo que pregunten.
- [ ] No enviar seguimiento el mismo día.

## Después de enviar

- [ ] Registrar canal real usado.
- [ ] Registrar fecha.
- [ ] Registrar hora.
- [ ] Registrar mensaje usado.
- [ ] Marcar estado como enviado.
- [ ] Calcular seguimiento 48-72h.
- [ ] Registrar si se guardó captura.

## Si no se puede enviar

- [ ] No marcar como enviado.
- [ ] Registrar motivo.
- [ ] Buscar canal alternativo.
- [ ] Mantener estado como canal no verificado o pendiente.
