# CHECKLIST VERIFICACIÓN MANUAL · La Quinta

## Antes de enviar

- [ ] Abrir Instagram.
- [ ] Buscar @laquintaantequera.
- [ ] Confirmar que parece cuenta oficial.
- [ ] Confirmar que está relacionada con La Quinta / Antequera.
- [ ] Confirmar actividad reciente.
- [ ] Confirmar que permite enviar mensaje.
- [ ] Revisar que el mensaje no promete pagos reales.
- [ ] Revisar que el mensaje no promete WhatsApp real.
- [ ] Revisar que el mensaje pide solo una demo breve.
- [ ] Preparar registro de envío antes de mandar.

## Si el canal no parece correcto

Buscar canal alternativo:

- web oficial
- teléfono
- email
- Instagram alternativo
- contacto de responsable

Enviar el mensaje una sola vez.

Después registrar fecha, hora y canal.
