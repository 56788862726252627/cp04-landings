# PAUSA ESTRATÉGICA · Club Matagrande

## Objetivo

Definir cómo pausar Club Matagrande sin perder el trabajo ya preparado.

## Cuándo usar pausa estratégica

Usar pausa si:

- el canal no está verificado
- Eduardo no quiere enviar todavía
- se prefiere cerrar primero La Quinta
- hay dudas sobre el mejor segundo club
- se quiere preparar mejor la demo antes de contactar

## Estado durante la pausa

| Campo | Valor |
|---|---|
| Club | Club Matagrande |
| Preparación comercial | Completa |
| Canal verificado | Pendiente |
| Mensaje preparado | Sí |
| Envío realizado | No |
| Seguimiento activo | No |
| Estado | Pausado / preparado |

## Qué se conserva

- ficha comercial
- mensaje adaptado
- mensaje definitivo
- checklist de canal
- criterios de envío
- registro pre-envío
- registro post-envío preparado
- matriz de riesgos

## Qué no se debe hacer

- no borrar documentación
- no marcar como enviado
- no activar seguimiento
- no mezclar con La Quinta
- no enviar si hay dudas

## Regla

Pausar no es retroceder.

Pausar permite ejecutar mejor cuando haya canal y decisión clara.
