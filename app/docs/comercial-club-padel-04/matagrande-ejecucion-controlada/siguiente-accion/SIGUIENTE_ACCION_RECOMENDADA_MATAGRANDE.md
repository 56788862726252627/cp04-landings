# SIGUIENTE ACCIÓN RECOMENDADA · Club Matagrande

## Objetivo

Definir la siguiente acción recomendada para Club Matagrande.

## Recomendación principal

Antes de enviar el mensaje, verificar canal real manualmente.

## Secuencia recomendada

1. Buscar canal oficial.
2. Confirmar que corresponde a Club Matagrande.
3. Elegir un único canal.
4. Revisar mensaje definitivo.
5. Decidir si enviar o pausar.
6. Si se envía, registrar fecha y hora.
7. Si no se envía, dejar estado como preparado, no contactado.

## Si Eduardo quiere ejecutar hoy

Acción:

- verificar canal
- copiar mensaje definitivo
- enviar una sola vez
- registrar envío real
- activar seguimiento 48-72h

## Si Eduardo quiere pausar

Acción:

- dejar Matagrande preparado
- no activar seguimiento
- pasar a revisar estrategia o siguiente club

## Regla final

La siguiente acción debe ser manual, controlada y registrada.
