## Criterios mínimos para ejecutar

- [ ] Canal oficial verificado.
- [ ] Un único canal elegido.

- [ ] Eduardo confirma envío manual.

## Criterios para pausar

- [ ] Canal no verificado.
- [ ] Varias cuentas posibles.
- [ ] Falta decisión de Eduardo.
- [ ] Falta cerrar estado real de La Quinta.
- [ ] Se quiere revisar estrategia antes.
- [ ] No se puede registrar correctamente.
