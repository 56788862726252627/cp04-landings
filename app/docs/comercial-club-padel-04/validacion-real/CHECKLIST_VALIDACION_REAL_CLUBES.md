# CHECKLIST VALIDACIÓN REAL · Clubes Pádel 04

## Antes de contactar

- [ ] Revisar que la app carga.
- [ ] Revisar guion de demo.
- [ ] Revisar checklist visual.
- [ ] Revisar objeciones.
- [ ] Elegir club objetivo.
- [ ] Localizar canal de contacto.
- [ ] Preparar mensaje corto.
- [ ] No enviar textos demasiado largos.
- [ ] No prometer WhatsApp si no está configurado.
- [ ] No prometer pagos si no están integrados.

## Durante el contacto

- [ ] Presentarse.
- [ ] Explicar en una frase qué se ofrece.
- [ ] Pedir demo de 10 minutos.
- [ ] No saturar con detalles técnicos.
- [ ] Registrar fecha y canal.
- [ ] Registrar respuesta.

## Durante la demo

- [ ] Preguntar cómo gestionan reservas.
- [ ] Mostrar solo lo importante.
- [ ] Enseñar roles.
- [ ] Enseñar reservas.
- [ ] Enseñar perfil.
- [ ] Enseñar admin.
- [ ] Explicar automatizaciones por fases.
- [ ] Cerrar con pregunta de interés.

## Después de la demo

- [ ] Registrar objeciones.
- [ ] Registrar interés.
- [ ] Registrar precio percibido.
- [ ] Registrar módulos pedidos.
- [ ] Enviar resumen.
- [ ] Preparar propuesta si hay interés.

## Métrica mínima de validación

Antes de crear otro vertical o gran bloque técnico:

- [ ] 5 clubes contactados.
- [ ] 2 respuestas reales.
- [ ] 1 demo propuesta.
- [ ] 1 feedback de precio o problema real.
