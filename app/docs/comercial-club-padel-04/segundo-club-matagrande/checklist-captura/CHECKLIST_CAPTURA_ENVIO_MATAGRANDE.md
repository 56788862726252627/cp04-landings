# CHECKLIST CAPTURA ENVÍO · Club Matagrande

## Objetivo

Definir qué capturas o pruebas guardar si se realiza el envío manual a Club Matagrande.

## Antes de enviar

Guardar o revisar:

- [ ] captura del perfil/canal verificado
- [ ] captura donde se vea que corresponde al club correcto
- [ ] captura del mensaje preparado antes de enviarlo si es posible
- [ ] canal elegido
- [ ] cuenta/contacto exacto
- [ ] fecha y hora aproximada

## Después de enviar

Registrar:

- [ ] captura del mensaje enviado si el canal lo permite
- [ ] fecha real
- [ ] hora real
- [ ] canal real usado
- [ ] mensaje exacto enviado o resumen fiel
- [ ] estado: enviado sin respuesta
- [ ] fecha mínima de seguimiento 48-72h

## Si no se puede guardar captura

Registrar manualmente:

- canal
- cuenta/contacto
- fecha
- hora
- motivo por el que no hay captura

## Si no se envía

Mantener:

- preparado, no contactado
- canal pendiente de verificar
- envío real: no

## Regla

No hace falta captura perfecta, pero sí un registro honesto y claro.
