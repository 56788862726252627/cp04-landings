# CRITERIOS ENVÍO CONTROLADO · Club Matagrande

## Objetivo

Definir cuándo sí y cuándo no enviar el primer mensaje real a Club Matagrande.

## Se puede enviar si

- [ ] El canal está verificado.
- [ ] El canal parece oficial.
- [ ] El perfil/contacto está activo.
- [ ] Se ha elegido un único canal.
- [ ] El mensaje definitivo está revisado.
- [ ] No se está enviando de forma masiva.
- [ ] Está abierto el registro de envío pendiente.
- [ ] Se puede registrar fecha y hora justo después.
- [ ] Eduardo decide hacer el envío manualmente.

## No se puede enviar si

- [ ] El canal no está verificado.
- [ ] Hay dudas de que sea el club correcto.
- [ ] Hay varias cuentas posibles.
- [ ] No se sabe qué mensaje usar.
- [ ] Se pretende enviar a varios canales a la vez.
- [ ] No se puede registrar el envío.
- [ ] El estado de La Quinta genera una acción urgente pendiente.

## Después de enviar

Registrar:

- canal real
- cuenta/contacto real
- fecha
- hora
- mensaje usado
- captura si procede
- estado: enviado sin respuesta

## Si no se envía

Mantener estado:

- preparado, no contactado
- canal pendiente de verificar

## Regla

Preparar no es enviar.

Enviar solo cuando el canal esté claro y Eduardo confirme la acción real.
