# CHECKLIST VERIFICACIÓN CANAL · Club Matagrande

## Objetivo

Verificar manualmente el canal antes de enviar cualquier mensaje real.

## Antes de enviar

- [ ] Buscar canal oficial de Club Matagrande.
- [ ] Confirmar que el perfil/canal parece activo.
- [ ] Confirmar que corresponde al club correcto.
- [ ] Confirmar que no es una cuenta duplicada o antigua.
- [ ] Confirmar que permite enviar mensaje.
- [ ] Revisar si hay email o teléfono visible.
- [ ] Elegir un único canal para el primer contacto.
- [ ] No enviar a varios canales a la vez.
- [ ] Tener abierto el registro de envío.
- [ ] Copiar el mensaje definitivo.
- [ ] Revisar que no se promete nada no validado.

## Si el canal es correcto

- [ ] Enviar una sola vez.
- [ ] Registrar fecha.
- [ ] Registrar hora.
- [ ] Registrar canal.
- [ ] Registrar cuenta/contacto.
- [ ] No insistir el mismo día.

## Si el canal no es correcto

- [ ] No enviar.
- [ ] Registrar canal incorrecto.
- [ ] Buscar canal alternativo.
- [ ] Mantener estado como no contactado.

## Regla

No contactar Club Matagrande hasta verificar canal.
