# CHECKLIST ANTI-DUPLICIDADES · Contacto comercial Club Pádel 04

## Objetivo

Evitar contactos repetidos, estados contradictorios y seguimientos duplicados.

## Antes de contactar un club

- [ ] Revisar tablero único de seguimiento.
- [ ] Confirmar que no existe envío real anterior.
- [ ] Confirmar que no existe seguimiento activo.
- [ ] Revisar registros del club.
- [ ] Revisar fecha y hora si existe envío anterior.
- [ ] Revisar canal usado anteriormente.
- [ ] Confirmar que el contacto no se ha realizado por otro canal.
- [ ] Elegir un único canal.
- [ ] Preparar mensaje específico.
- [ ] Tener registro post-envío preparado.

## Después de enviar

- [ ] Registrar envío real.
- [ ] Registrar fecha.
- [ ] Registrar hora.
- [ ] Registrar canal.
- [ ] Registrar cuenta/contacto.
- [ ] Guardar captura si procede.
- [ ] Marcar estado como enviado sin respuesta.
- [ ] Programar revisión 48-72h.
- [ ] No volver a enviar inmediatamente.

## Antes de seguimiento

- [ ] Confirmar primer envío.
- [ ] Confirmar ausencia de respuesta.
- [ ] Confirmar que ha pasado el plazo.
- [ ] Revisar si hubo respuesta por otro canal.
- [ ] Hacer un único seguimiento.
- [ ] Registrar el seguimiento.

## Señales de posible duplicidad

- dos registros para el mismo club
- varios canales marcados como activos
- fecha de envío vacía pero estado enviado
- seguimiento activo sin envío previo
- dos mensajes distintos enviados el mismo día
- respuesta registrada sin contacto real previo

## Acción ante duda

No enviar.

Primero consolidar el estado real.

## Regla final

La documentación preparada nunca debe confundirse con una acción comercial ejecutada.
