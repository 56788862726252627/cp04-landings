# MODELO DE CAPACIDAD REAL DE SEGUIMIENTO · Club Pádel 04

## Objetivo

Definir cómo saber si existe capacidad real para contactar más clubes.

## Preguntas de control

Antes de abrir un nuevo contacto:

- ¿Todos los envíos reales están registrados?
- ¿Todos los seguimientos pendientes tienen fecha?
- ¿Todas las respuestas están contestadas?
- ¿Existe una demo lista?
- ¿La propuesta comercial está clara?
- ¿Existe tiempo para atender una llamada o demo?
- ¿Se puede hacer onboarding si el club acepta?

## Semáforo operativo

### Verde

Se puede abrir nuevo contacto si:

- no hay respuestas pendientes
- no hay seguimientos vencidos
- el tablero está actualizado
- hay capacidad de demo

### Amarillo

No abrir más de un contacto si:

- hay seguimiento próximo
- hay una demo pendiente
- existe una respuesta por preparar

### Rojo

No abrir nuevos contactos si:

- existen respuestas sin atender
- hay seguimientos vencidos
- no se conoce el estado real de clubes activos
- existe riesgo de duplicidad
- la demo presenta problemas funcionales críticos

## Indicadores mínimos

Registrar:

- contactos activos
- respuestas pendientes
- seguimientos pendientes
- demos propuestas
- demos agendadas
- negociaciones activas
- ventas cerradas

## Regla

El crecimiento comercial debe medirse por capacidad de respuesta, no por número de mensajes enviados.
