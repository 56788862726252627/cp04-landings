# CHECKLIST DE DEMO COMERCIAL · Club Pádel 04

## Antes de la demo

Comprobar:

- la app carga correctamente
- no hay pantalla negra
- el enlace local o demo funciona
- el modo demo está listo
- no se muestran claves ni datos sensibles
- el perfil se ve presentable
- el dashboard se ve estable
- los módulos principales funcionan visualmente
- Chrome está limpio y con zoom adecuado
- batería suficiente
- terminal 1 mantiene la app abierta
- terminal 2 no está haciendo cambios durante la demo

---

## Orden recomendado de presentación

1. Presentación breve del problema.
2. Pantalla de inicio.
3. Reservas.
4. Perfil y ajustes.
5. Roles.
6. Automatizaciones.
7. Panel administrativo.
8. Mantenimiento mensual.
9. Precio orientativo.
10. Preguntas del club.

---

## Qué decir al principio

Lo que quiero enseñarte no es una web normal. Es una base SaaS para digitalizar reservas, socios, procesos y automatizaciones de un club deportivo.”

---

## Qué mostrar primero

Mostrar la pantalla de inicio y explicar:

- imagen moderna
- acceso a módulos
- métricas
- estado operativo
- experiencia premium

---

## Qué evitar en la demo

No entrar demasiado en:

- código
- errores pasados
- terminal
- problemas de CSS
- detalles técnicos internos
- backups
- auditorías largas
- herramientas que el cliente no necesita entender

---

## Preguntas clave al cliente

- ¿Cómo gestionáis ahora las reservas?
- ¿Qué tarea os quita más tiempo?
- ¿Cuántas personas gestionan el club?
- ¿Qué herramientas usáis actualmente?
- ¿Qué os gustaría automatizar primero?
- ¿Os interesa más una app, automatizaciones o ambas?
- ¿Qué presupuesto mensual tendría sentido si el sistema ahorra tiempo?

---

## Cierre de la demo

Si esto os encaja, el siguiente paso sería preparar una versión adaptada a vuestro club con marca, módulos prioritarios y una propuesta de implantación.”
