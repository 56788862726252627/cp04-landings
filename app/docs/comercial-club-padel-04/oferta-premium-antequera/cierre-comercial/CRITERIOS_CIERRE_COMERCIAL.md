# CRITERIOS DE CIERRE COMERCIAL · Club Pádel 04

## Objetivo

Definir cuándo una oportunidad está realmente preparada para cerrar.

## Señales de cierre

- existe necesidad clara
- el decisor participa
- el alcance está entendido
- el precio está comprendido
- las objeciones principales están resueltas
- el siguiente paso está acordado
- existe voluntad explícita de avanzar

## No considerar cierre si

- solo hay interés verbal
- no existe decisor
- el precio no ha sido discutido
- no hay alcance definido
- no existe siguiente paso
- el club sigue comparando sin decisión

## Preguntas de cierre

- ¿hay algún punto que impida avanzar?
- ¿el alcance cubre vuestra necesidad principal?
- ¿qué necesitaríais para tomar una decisión?
- ¿tiene sentido definir fecha de inicio?
- ¿preferís piloto o implantación completa?

## Resultados posibles

### Cierre

Preparar firma y onboarding.

### Pendiente

Definir acción y fecha.

### Pausa

Registrar motivo y fecha de revisión.

### Rechazo

Registrar aprendizaje.

## Regla

Cerrar significa confirmar una decisión.

No presionar para crear una decisión artificial.
