# SELECCIÓN FINAL DE PANTALLAS · Demo comercial Antequera

## Objetivo

Definir qué pantallas deben utilizarse en la demo comercial y cuáles deben excluirse.

## Criterios

Cada pantalla se clasifica como:

- APTO
- APTO CON MEJORA
- REVISAR
- EXCLUIR
- RESERVA
