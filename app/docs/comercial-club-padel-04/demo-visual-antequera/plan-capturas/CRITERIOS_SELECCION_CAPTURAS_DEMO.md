# CRITERIOS DE SELECCIÓN DE CAPTURAS · Demo Antequera

## Una captura comercial debe cumplir

- composición limpia
- datos demo coherentes
- ausencia de errores
- ausencia de credenciales
- ausencia de información privada
- buena jerarquía
- contraste suficiente
- navegación comprensible
- identidad coherente
- mensaje comercial claro

## Una captura debe excluirse cuando contiene

- terminal
- logs
- datos sensibles
- claves
- errores
- contenido vacío
- datos incoherentes
- botones rotos
- texto provisional
- elementos visuales sin terminar

## Orden previsto

1. impacto visual
2. disponibilidad
3. reserva
4. confirmación
5. actividad
6. comunidad
7. gestión
8. ocupación
9. automatización
10. métricas
11. IA

## Regla

Cada captura debe responder a una pregunta:

Qué valor demuestra esta pantalla?
