# GUÍA DE IDENTIDAD VISUAL · Demo Antequera

## Contexto

La versión comercial actual de Club Pádel 04 debe tratarse como diseñada especialmente para un club de pádel de Antequera.

## Elemento visual principal

El Torcal de Antequera.

## Integración recomendada

El paisaje debe aportar:

- reconocimiento
- identidad
- profundidad
- carácter premium

No debe competir con:

- botones
- formularios
- textos
- navegación

## Pista de pádel

La pista debe integrarse de manera realista y premium.

Debe evitar:

- aspecto artificial
- proporciones incorrectas
- iluminación incoherente
- saturación visual

## Atardecer

Debe aportar:

- calidez
- profundidad
- emoción
- calidad cinematográfica moderada

Sin dificultar la lectura.

## Principio

Antequera es la identidad comercial inicial.

La arquitectura de producto debe seguir siendo adaptable a otros clubes y localidades.
