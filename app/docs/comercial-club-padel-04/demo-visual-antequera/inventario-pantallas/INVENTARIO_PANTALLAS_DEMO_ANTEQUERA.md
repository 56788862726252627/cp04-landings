# INVENTARIO DE PANTALLAS PARA DEMO · Antequera

## Objetivo

Seleccionar únicamente las pantallas que aportan valor en una reunión comercial.

## Bloque A · Impacto inicial

Revisar:

- acceso
- portada
- dashboard principal
- identidad visual

## Bloque B · Experiencia del jugador

Revisar:

- disponibilidad
- reserva
- confirmación
- mis reservas
- perfil

## Bloque C · Comunidad

Revisar:

- ranking
- torneos
- emparejamientos
- eventos

## Bloque D · Operación

Revisar:

- dashboard empleado
- reservas
- pistas
- ocupación
- jugadores
- incidencias

## Bloque E · Dirección

Revisar:

- dashboard gerente
- métricas
- informes
- actividad
- tendencias

## Bloque F · Diferenciación

Revisar:

- automatizaciones
- IA
- soporte
- asistentes especializados

## Criterio comercial

Una pantalla debe entrar en la demo solo cuando permite demostrar claramente uno o más de estos valores:

- ahorro de tiempo
- reducción de fricción
- más control
- mejor ocupación
- fidelización
- decisiones basadas en datos
- diferenciación
