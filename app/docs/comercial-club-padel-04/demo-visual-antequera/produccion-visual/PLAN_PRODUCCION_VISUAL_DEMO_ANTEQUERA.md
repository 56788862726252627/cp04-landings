# PLAN DE PRODUCCIÓN VISUAL · Demo comercial Antequera

## Objetivo

Transformar la arquitectura documental de la demo en activos comerciales visuales reales, verificables y reutilizables.

---

# FASE 1 · PREPARAR LA APP

Antes de realizar capturas:

- comprobar build
- abrir app estable
- verificar rutas
- verificar roles
- cargar datos demo
- eliminar datos incoherentes
- comprobar botones
- comprobar textos
- comprobar responsive
- ocultar credenciales
- ocultar logs

## Resultado esperado

Aplicación preparada para captura comercial.

---

# FASE 2 · CAPTURAS PRIORIDAD 1

Producir primero:

1. inicio Antequera
2. disponibilidad
3. reserva
4. confirmación
5. dashboard del club
6. ocupación
7. métricas
8. automatizaciones

## Motivo

Estas pantallas permiten explicar la propuesta principal:

jugador

 reserva

 operación

 datos

 automatización

---

# FASE 3 · CAPTURAS PRIORIDAD 2

Producir:

- mis reservas
- perfil
- ranking
- torneos
- CRM
- soporte
- IA

## Motivo

Aportan:

- fidelización
- comunidad
- gestión
- diferenciación

---

# FASE 4 · CAPTURAS PRIORIDAD 3

Producir cuando sean necesarias:

- selección pista-horario
- emparejamientos
- reservas staff
- incidencias
- actividad
- informes

---

# FASE 5 · NORMALIZACIÓN

Todas las capturas deben usar:

- mismo entorno visual
- tamaños consistentes
- datos demo coherentes
- nomenclatura comercial clara
- fechas controladas
- sin información personal real

---

# FASE 6 · MOCKUPS

Crear:

## Hero

Antequera + Torcal + pista + dispositivo.

## Móvil

Experiencia del jugador.

## Tablet

Gestión y ocupación.

## Escritorio

Métricas y dirección.

## Automatización

Flujo simplificado de valor.

## IA

Orquestación y respuesta especializada.

---

# FASE 7 · MATERIALES COMERCIALES

Producir:

- dossier visual
- presentación ejecutiva
- one-page visual
- tabla visual de paquetes
- cronograma de implantación
- gráfico ROI orientativo
- infografía de automatizaciones

---

# FASE 8 · VALIDACIÓN

Cada activo debe revisarse en:

- legibilidad
- coherencia
- exactitud
- seguridad
- fidelidad al producto
- calidad visual
- utilidad comercial

---

# PRINCIPIO

No producir activos por volumen.

Cada activo debe tener una función comercial concreta.
