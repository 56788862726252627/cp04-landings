# MATRIZ DE CIERRE, PAUSA O RECHAZO · Club Pádel 04

## Objetivo

Cerrar cada oportunidad con un estado real y una próxima acción coherente.

## Venta cerrada

Usar cuando existe aceptación confirmada.

Registrar:

- fecha
- alcance
- precio
- condiciones
- contacto decisor
- siguiente paso de onboarding

## Pausa

Usar cuando:

- no es el momento
- falta presupuesto temporal
- existe contrato vigente
- existe interés futuro
- falta decisión interna

Registrar:

- motivo
- fecha futura de revisión
- persona de contacto

## Rechazo

Usar cuando:

- no existe interés
- el club rechaza continuar
- no existe encaje
- se pierde la oportunidad definitivamente

Registrar:

- motivo
- aprendizaje
- objeción principal

## Sin respuesta

No confundir con rechazo.

Acción:

- ejecutar seguimiento según reglas
- cerrar como sin respuesta solo después del ciclo definido

## Regla

Toda oportunidad debe terminar con un estado claro.

No dejar oportunidades indefinidamente abiertas.
