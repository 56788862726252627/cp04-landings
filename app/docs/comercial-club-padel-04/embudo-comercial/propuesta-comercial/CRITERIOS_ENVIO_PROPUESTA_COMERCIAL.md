# CRITERIOS PARA ENVIAR PROPUESTA COMERCIAL · Club Pádel 04

## Objetivo

Evitar enviar propuestas demasiado pronto o sin contexto suficiente.

## Enviar propuesta si

- existe interés real
- la demo se ha realizado o el alcance está claramente entendido
- existe una necesidad concreta
- se conoce quién decide
- se conoce el alcance básico
- se puede definir precio o rango
- existe siguiente paso claro

## No enviar propuesta si

- solo existe curiosidad
- no existe contacto con decisor
- no se entiende la necesidad
- el club no ha mostrado interés real
- no se sabe qué paquete ofrecer
- el precio sería completamente improvisado

## Contenido mínimo

Toda propuesta debe incluir:

- contexto del club
- problema identificado
- solución propuesta
- alcance
- módulos incluidos
- automatizaciones
- implantación
- soporte
- mantenimiento
- precio
- condiciones
- siguiente paso

## Regla

Una propuesta debe responder a una necesidad concreta.

No debe ser un catálogo genérico.
