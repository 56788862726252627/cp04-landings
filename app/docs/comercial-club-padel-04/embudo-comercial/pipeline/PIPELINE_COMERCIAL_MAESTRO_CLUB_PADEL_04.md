# PIPELINE COMERCIAL MAESTRO · Club Pádel 04

## Objetivo

Crear un embudo comercial único, medible y replicable desde el primer contacto hasta el cierre.

## Pipeline principal

1. Candidato identificado.
2. Preparación comercial.
3. Canal verificado.
4. Contacto autorizado.
5. Contacto real enviado.
6. Respuesta recibida.
7. Lead calificado.
8. Demo propuesta.
9. Demo agendada.
10. Demo realizada.
11. Propuesta comercial enviada.
12. Negociación.
13. Venta cerrada.
14. Pausa.
15. Rechazo documentado.

## Principio operativo

Cada club debe tener:

- una etapa actual
- una próxima acción
- una fecha de revisión
- un responsable
- evidencia cuando exista una acción real

## Pipeline resumido

| Etapa | Estado | Acción siguiente |
|---|---|---|
| Candidato | Identificado | Preparar ficha |
| Preparado | Propuesta preparada | Verificar canal |
| Canal verificado | Contacto localizado | Autorizar contacto |
| Contactado | Mensaje enviado | Esperar respuesta |
| Respondido | Interacción real | Calificar interés |
| Calificado | Interés válido | Proponer demo |
| Demo propuesta | Invitación enviada | Agendar |
| Demo agendada | Fecha confirmada | Preparar demo |
| Demo realizada | Presentación completada | Enviar propuesta |
| Propuesta enviada | Oferta entregada | Negociar |
| Negociación | Condiciones en revisión | Cerrar |
| Venta cerrada | Cliente confirmado | Onboarding |
| Pausado | Oportunidad detenida | Revisar fecha |
| Rechazado | Oportunidad cerrada | Registrar motivo |

## Regla

Ningún club puede saltar etapas sin evidencia real.

Una demo no se considera agendada sin fecha confirmada.

Una propuesta no se considera enviada sin envío real.

Una venta no se considera cerrada sin acuerdo confirmado.
