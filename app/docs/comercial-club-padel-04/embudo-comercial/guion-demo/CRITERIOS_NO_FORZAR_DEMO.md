# CRITERIOS PARA NO FORZAR UNA DEMO · Club Pádel 04

## Objetivo

Evitar demos prematuras que consuman tiempo o generen rechazo.

## No proponer demo si

- no existe respuesta real
- el interés es claramente bajo
- el contacto no es el adecuado
- existe rechazo explícito
- no hay problema identificado
- el club pide solo información básica
- la demo no puede adaptarse a su contexto
- existen fallos críticos pendientes de resolver

## Proponer demo si

- existe necesidad concreta
- hay interés real
- preguntan funciones
- preguntan precio
- solicitan explicación
- quieren ver funcionamiento
- existe acceso al decisor

## Señales positivas

- preguntas concretas
- respuestas rápidas
- curiosidad por implantación
- interés por ahorro
- interés por automatización
- preocupación por gestión actual

## Señales de pausa

- respuestas muy vagas
- demora extrema sin interés
- cambio frecuente de contacto
- falta de decisor
- rechazo a cualquier conversación

## Regla

Una demo debe ser consecuencia del interés, no un intento desesperado de crearlo.
