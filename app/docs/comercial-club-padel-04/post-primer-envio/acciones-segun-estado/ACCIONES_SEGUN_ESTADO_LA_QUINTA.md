# ACCIONES SEGÚN ESTADO · La Quinta

## Caso A · Todavía no enviado

Acción:

1. Verificar canal.
2. Enviar solo si el canal es correcto.
3. Registrar datos reales.

Estado recomendado:

- Pendiente envío real.

## Caso B · Enviado correctamente

Acción:

1. Registrar fecha y hora.
2. Registrar canal usado.
3. Registrar mensaje enviado.
4. Esperar respuesta.
5. Calcular seguimiento 48-72h.

Estado recomendado:

- Enviado sin respuesta.
- Seguimiento pendiente.

## Caso C · No se pudo enviar

Acción:

1. Registrar motivo.
2. Buscar canal alternativo.
3. No marcar enviado.
4. Preparar nuevo intento controlado.

Estado recomendado:

- Canal no verificado.
- Buscar canal alternativo.

## Caso D · Respuesta positiva

Acción:

1. Responder breve.
2. Proponer demo 10-15 minutos.
3. Registrar interés.
4. Preparar guion demo.
5. No improvisar propuesta final.

Estado recomendado:

- Interesado.
- Demo propuesta.

## Caso E · Respuesta negativa

Acción:

1. Agradecer.
2. Registrar rechazo.
3. No insistir.
4. Guardar aprendizaje.

Estado recomendado:

- Rechazado.
- Cerrado.

## Caso F · Objeción

Acción:

1. Registrar objeción literal.
2. Responder de forma breve.
3. No discutir.
4. Mejorar propuesta con ese aprendizaje.

Estado recomendado:

- Objeción registrada.
