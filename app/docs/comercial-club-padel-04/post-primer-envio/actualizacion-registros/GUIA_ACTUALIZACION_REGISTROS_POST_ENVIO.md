# GUÍA ACTUALIZACIÓN REGISTROS POST ENVÍO

## Objetivo

Saber qué documentos actualizar según lo que haya ocurrido realmente con el primer envío.

## Si el mensaje fue enviado

Actualizar:

1. REGISTRO_REAL_POST_ENVIO_LA_QUINTA.md
2. REGISTRO_CONTROL_DECISION_LA_QUINTA.md
3. SEGUIMIENTO_48_72H_POST_ENVIO_LA_QUINTA.md
4. TABLERO_DECISION_ESTADO_REAL_ENVIO_LA_QUINTA.md si procede

## Si el mensaje no fue enviado

Actualizar:

1. COMPROBACION_ENVIO_REAL_LA_QUINTA.md
2. REGISTRO_CONTROL_DECISION_LA_QUINTA.md

Estado recomendado:

- No enviado
- Pendiente de envío real

## Si el canal era incorrecto

Actualizar:

1. COMPROBACION_ENVIO_REAL_LA_QUINTA.md
2. REGISTRO_REAL_POST_ENVIO_LA_QUINTA.md
3. REGISTRO_CONTROL_DECISION_LA_QUINTA.md

Estado recomendado:

- Canal incorrecto
- Buscar canal alternativo

## Si hubo respuesta

Actualizar:

1. REGISTRO_RESPUESTA_LA_QUINTA.md
2. REGISTRO_REAL_POST_ENVIO_LA_QUINTA.md
3. REGISTRO_CONTROL_DECISION_LA_QUINTA.md
4. ACCIONES_SEGUN_ESTADO_LA_QUINTA.md si procede

## Si no hubo respuesta tras envío

Actualizar:

1. REGISTRO_REAL_POST_ENVIO_LA_QUINTA.md
2. SEGUIMIENTO_48_72H_POST_ENVIO_LA_QUINTA.md
3. REGISTRO_CONTROL_DECISION_LA_QUINTA.md

Estado recomendado:

- Enviado sin respuesta
- Seguimiento pendiente

## Regla

Actualizar solo con hechos reales.
