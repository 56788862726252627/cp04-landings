# CHECKLIST FINAL COMPROBACIÓN REAL · La Quinta

## Objetivo

Comprobar el estado real del primer envío comercial a La Quinta antes de cerrar la auditoría.

## Pregunta principal

Se ha enviado realmente el mensaje?

## Opciones válidas

- [ ] Sí, enviado.
- [ ] No, todavía no enviado.
- [ ] No se pudo enviar.
- [ ] Canal incorrecto.
- [ ] Canal pendiente de verificar.
- [ ] Respuesta recibida.
- [ ] Seguimiento pendiente.

## Si está enviado

Comprobar que están registrados:

- [ ] canal real usado
- [ ] cuenta/contacto real
- [ ] fecha real
- [ ] hora real
- [ ] mensaje exacto o resumen fiel
- [ ] captura si procede
- [ ] estado actual
- [ ] fecha mínima de seguimiento

## Si no está enviado

Comprobar que NO se haya marcado como enviado.

Mantener estado:

- pendiente envío real
- pendiente verificación canal

## Si respondió

Registrar:

- [ ] fecha respuesta
- [ ] hora respuesta
- [ ] respuesta literal o resumen fiel
- [ ] tipo de respuesta
- [ ] objeción si existe
- [ ] acción recomendada

## Regla final

No cerrar como hecho real algo que todavía no ha pasado.
