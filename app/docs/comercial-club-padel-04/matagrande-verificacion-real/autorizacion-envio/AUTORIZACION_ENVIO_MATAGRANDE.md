# AUTORIZACIÓN DE ENVÍO · Club Matagrande

## Objetivo

Definir si el mensaje a Club Matagrande queda autorizado o no autorizado para envío manual.

## Estado actual

Club Matagrande está preparado, pero no contactado.

## Decisión de autorización

| Campo | Valor |
|---|---|
| Club | Club Matagrande |
| Canal verificado | Pendiente |
| Canal elegido | Pendiente |
| Contacto elegido | Pendiente |
| Mensaje definitivo listo | Sí |
| Envío autorizado | Pendiente |
| Envío realizado | No |
| Responsable de confirmar | Eduardo |
| Próximo paso | Confirmar canal real |

## Opciones válidas

- Autorizado para envío manual.
- No autorizado por canal pendiente.
- No autorizado por canal incorrecto.
- No autorizado por varias cuentas posibles.
- No autorizado por falta de decisión.
- Pausado.

## Si queda autorizado

Eduardo puede enviar manualmente una sola vez usando el mensaje definitivo.

Después debe registrar:

- canal real
- cuenta/contacto real
- fecha
- hora
- captura si procede
- estado: enviado sin respuesta

## Si no queda autorizado

No se envía.

Se mantiene:

- preparado, no contactado
- seguimiento no activo
- registro pendiente

## Regla

No hay autorización real hasta que Eduardo confirme manualmente el canal y decida enviar.
