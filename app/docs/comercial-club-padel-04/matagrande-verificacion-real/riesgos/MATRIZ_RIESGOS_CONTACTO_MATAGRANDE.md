# MATRIZ RIESGOS CONTACTO · Club Matagrande

## Objetivo

Evitar errores antes de contactar al segundo club.

## Riesgos

| Riesgo | Impacto | Prevención |
|---|---|---|
| Contactar cuenta incorrecta | Alto | Verificar canal antes |
| Enviar dos veces | Medio | Usar un único canal |
| Mensaje demasiado largo | Medio | Usar mensaje definitivo |
| Prometer funciones no listas | Alto | No mencionar pagos/WhatsApp real |
| Perder seguimiento de La Quinta | Medio | Mantener registros separados |
| Marcar enviado sin enviar | Alto | Confirmación manual de Eduardo |
| No registrar fecha/hora | Medio | Actualizar registro justo después |
| Parecer spam | Alto | Mensaje breve y humano |

## Regla

La verificación protege la reputación comercial del proyecto.
