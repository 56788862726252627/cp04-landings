# CHECKLIST FINAL DE VENTA · Club Pádel 04

## Antes de contactar al club

- [ ] Tener nombre del club.
- [ ] Tener ciudad.
- [ ] Saber número aproximado de pistas.
- [ ] Saber canal de contacto.
- [ ] Tener mensaje preparado.
- [ ] Tener demo revisada.
- [ ] Tener propuesta base preparada.
- [ ] Tener límites claros.

## Durante el contacto

- [ ] Presentarse de forma breve.
- [ ] No sonar demasiado técnico.
- [ ] Hablar de ahorro de tiempo.
- [ ] Hablar de reservas.
- [ ] Hablar de jugadores.
- [ ] Hablar de administración.
- [ ] Pedir 10 minutos para enseñar demo.
- [ ] No enviar demasiada información de golpe.

## Durante la demo

- [ ] Empezar preguntando cómo gestionan reservas.
- [ ] Enseñar solo lo importante.
- [ ] Evitar módulos incompletos.
- [ ] Explicar límites de demo.
- [ ] No prometer pagos reales si no están listos.
- [ ] No prometer WhatsApp si no está configurado.
- [ ] No abrir terminal.
- [ ] No abrir Make/Airtable con credenciales.
- [ ] Cerrar preguntando interés real.

## Después de la demo

- [ ] Enviar resumen breve.
- [ ] Anotar objeciones.
- [ ] Anotar módulos que pidieron.
- [ ] Anotar precio percibido.
- [ ] Preparar propuesta adaptada si hay interés.
- [ ] No hacer cambios técnicos grandes sin validación.

## Señales para preparar propuesta

- [ ] Preguntan precio.
- [ ] Preguntan cuándo estaría listo.
- [ ] Preguntan si se puede adaptar.
- [ ] Cuentan problemas internos.
- [ ] Quieren enseñarlo a otro socio/responsable.
- [ ] Piden siguiente llamada.
