# CHECK TÉCNICO PRE-DEMO · Club Pádel 04

## Objetivo

Comprobar que la app está suficientemente estable para enseñarla a un club real sin tocar código funcional salvo error crítico.

## Antes de abrir la demo

- [ ] Ejecutar `npm run build`.
- [ ] Confirmar build correcto.
- [ ] Confirmar que no hay cambios sin guardar en Git.
- [ ] Confirmar que no hay tokens visibles.
- [ ] Confirmar que no hay credenciales visibles.
- [ ] Confirmar que no se muestran datos privados reales.
- [ ] Confirmar que la app abre en local.
- [ ] Confirmar que la ruta demo carga.

## Revisión visual mínima

- [ ] La pantalla inicial carga.
- [ ] El fondo visual se ve correcto.
- [ ] El sidebar no tapa contenido importante.
- [ ] Perfil y ajustes se ve legible.
- [ ] El selector de idioma no rompe la vista.
- [ ] Los botones principales son legibles.
- [ ] No hay parpadeos rojos extraños.
- [ ] No hay pantalla negra.
- [ ] No hay scroll roto.
- [ ] No hay textos cortados importantes.
- [ ] No hay módulos duplicados visibles.
- [ ] No hay nombres de Playtomic ni Vola.
- [ ] No hay marcas externas visibles.

## Revisión funcional mínima

- [ ] Se puede navegar por el menú.
- [ ] Se puede explicar el flujo de reservas.
- [ ] Se puede explicar el panel de administración.
- [ ] Se puede explicar el perfil.
- [ ] Se puede explicar el valor de automatizaciones.
- [ ] Se puede salir de una vista sin bloquearse.
- [ ] No hay errores críticos visibles.

## No probar en demo real

- [ ] Pagos reales.
- [ ] Cancelaciones reales.
- [ ] WhatsApp real.
- [ ] Webhooks reales.
- [ ] Make real.
- [ ] Airtable real.
- [ ] Credenciales.
- [ ] Terminal.
- [ ] Archivos internos.

## Decisión

La demo se considera enseñable si:

- carga correctamente
- no hay pantalla negra
- el flujo principal se entiende
- visualmente no hay errores graves
- se pueden explicar los límites
