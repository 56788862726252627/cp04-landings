# CHECKLIST · ¿Se puede pasar al siguiente club?

## Objetivo

Evitar avanzar a más clubes sin tener controlado el estado del primer contacto.

## Condiciones mínimas para avanzar

Se puede pasar al siguiente club solo si se cumple al menos una de estas situaciones:

- [ ] El mensaje a La Quinta fue enviado y está registrado.
- [ ] El mensaje no fue enviado, pero el estado quedó claramente marcado como no enviado.
- [ ] El canal era incorrecto y quedó registrado.
- [ ] El canal no permite mensaje y quedó registrado.
- [ ] Hay respuesta y quedó registrada.
- [ ] Hay seguimiento pendiente con fecha mínima clara.
- [ ] Se decidió conscientemente pausar La Quinta y pasar al siguiente club.

## No avanzar si

- [ ] No se sabe si el mensaje fue enviado.
- [ ] No se sabe qué canal se usó.
- [ ] No se sabe si hubo respuesta.
- [ ] No se ha definido próximo paso.
- [ ] Se está mezclando preparación con ejecución real.

## Decisión

| Pregunta | Respuesta |
|---|---|
| ¿Estado del primer club claro? | Pendiente |
| ¿Registro actualizado? | Pendiente |
| ¿Hay siguiente acción definida? | Pendiente |
| ¿Se puede pasar al siguiente club? | Pendiente |

## Regla

Avanzar no significa abandonar el primer club.

Avanzar significa que el primer club tiene un estado claro.
