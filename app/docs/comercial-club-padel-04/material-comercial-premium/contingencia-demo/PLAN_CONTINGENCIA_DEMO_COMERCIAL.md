# PLAN DE CONTINGENCIA DE DEMO COMERCIAL

## Objetivo

Evitar que una reunión dependa completamente de una demo en directo.

## Riesgos

- fallo de conexión
- caída de túnel
- URL no disponible
- error de navegador
- sesión cerrada
- datos demo inconsistentes
- pantalla bloqueada
- dispositivo sin batería

## Nivel 1 · Demo en directo

Opción principal.

Requisitos:

- app accesible
- sesión preparada
- navegación probada
- datos demo revisados

## Nivel 2 · Capturas ordenadas

Disponer de capturas de:

1. inicio
2. disponibilidad
3. reserva
4. confirmación
5. panel
6. ocupación
7. automatizaciones
8. ranking
9. torneos
10. métricas

## Nivel 3 · Dossier

Usar dossier comercial como soporte narrativo.

## Nivel 4 · One-page

Usar resumen ejecutivo para continuar conversación.

## Mensaje ante fallo

Podemos seguir perfectamente. Tengo preparado el recorrido visual y os explico el flujo completo mientras recuperamos el acceso.

## Nunca hacer

- entrar en pánico
- ejecutar comandos delante del cliente
- mostrar errores internos
- abrir terminales con información sensible
- improvisar credenciales
- culpar a terceros

## Regla

La demo debe tener al menos dos alternativas de respaldo.
