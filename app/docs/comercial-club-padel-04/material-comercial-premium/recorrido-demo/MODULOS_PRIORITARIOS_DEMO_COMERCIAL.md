# MÓDULOS PRIORITARIOS PARA DEMO COMERCIAL

## Objetivo

Priorizar módulos con impacto comercial.

## Prioridad A · Mostrar casi siempre

- disponibilidad
- reserva
- gestión de reservas
- ocupación
- panel operativo
- automatizaciones

## Prioridad B · Mostrar según conversación

- perfil
- ranking
- torneos
- promociones
- CRM
- incidencias
- métricas

## Prioridad C · Mostrar con interés avanzado

- asistentes IA
- soporte técnico
- automatización avanzada
- configuración
- personalización
- analítica avanzada

## Regla

Una demo comercial no es una auditoría funcional.

No hay que mostrarlo todo.

## Criterio

Mostrar un módulo solo si ayuda a demostrar:

- ahorro
- control
- ocupación
- experiencia
- fidelización
- diferenciación
