# Club Pádel 04 · Checklist capturas visuales recomendadas

- [ ] Inicio con banner demo.

## Qué mirar en cada captura

- [ ] Banner visible.
- [ ] Banner no tapa botones.
- [ ] Texto legible.
- [ ] Diseño profesional.
- [ ] No hay datos sensibles.
- [ ] No parece producción real.
- [ ] No hay errores visuales graves.

## Prioridad

Alta:

- Banner tapa botones principales.
- App queda inutilizable.
- Se expone información sensible.
- El diseño se rompe claramente.

Media:

- Banner ocupa demasiado.
- Texto largo en móvil.
- Hay solapes leves.

Baja:

- Ajustes de espaciado.
- Pequeñas mejoras estéticas.
