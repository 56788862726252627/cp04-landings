# Club Pádel 04 · Auditoría 51 · Checklist validación visual real 25%

## Objetivo

Validar visualmente el modo demo seguro antes de enseñar la app a clientes.

## Comprobaciones en navegador

- [ ] El banner de modo demo aparece visible.
- [ ] El banner no tapa botones importantes.
- [ ] El banner se entiende rápido.
- [ ] El diseño no se rompe en móvil.
- [ ] El diseño no se rompe en tablet.
- [ ] El diseño no se rompe en escritorio.
- [ ] La app mantiene aspecto profesional.
- [ ] Las rutas principales cargan correctamente.
- [ ] Las zonas de reservas se siguen viendo bien.
- [ ] El panel admin se sigue viendo bien.
- [ ] El soporte técnico se sigue viendo bien.
- [ ] No aparecen errores visuales graves.

## Seguridad

- [ ] No hay pagos reales activos.
- [ ] No hay reservas reales activas.
- [ ] No hay cancelaciones reales activas.
- [ ] No se exponen tokens.
- [ ] No se exponen webhooks.
- [ ] No se muestra arquitectura interna.
- [ ] No se ha tocado DNS.
- [ ] No se ha conectado dominio definitivo.

## Resultado esperado

La demo debe ser segura, visualmente clara y presentable para Archidona y Antequera.
