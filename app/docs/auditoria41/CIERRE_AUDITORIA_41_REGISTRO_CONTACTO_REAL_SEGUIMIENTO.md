Preparar el sistema documental para registrar contactos reales con clubes, respuestas, objeciones, seguimientos y posibles demos de Club Pádel 04.

- Pendientes de registrar fecha/hora/canal reales.

## Regla principal

No marcar ningún club como contactado hasta haber enviado realmente el mensaje.

Después de enviar, registrar:

- club
- canal usado
- dato de contacto usado
- fecha
- hora
- mensaje usado
- respuesta
- objeción
- próximo paso

## Criterio para seguimiento

Si no hay respuesta:

- esperar 48-72 horas
- enviar seguimiento breve
- registrar seguimiento
- no insistir el mismo día

## Criterio para pasar a demo

Proponer demo si el club:

- pide más información
- pregunta precio
- pregunta funcionalidades
- pregunta cómo funciona
- deriva a responsable
- acepta verlo
- muestra interés real

## Qué evitar

No hacer:

- enviar propuesta completa en primer mensaje
- enviar PDF largo sin que lo pidan
- hablar demasiado de código
- abrir terminal en demo
- prometer WhatsApp real si no está configurado
- prometer pagos reales si no están cerrados
- decir que ya hay clubes implantados si aún no los hay

## Objetivo real de la siguiente fase
