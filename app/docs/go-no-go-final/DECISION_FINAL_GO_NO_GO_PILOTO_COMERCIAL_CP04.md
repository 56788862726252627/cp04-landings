# Club Pádel 04 · Decisión final go/no-go piloto comercial

## Decisión final

GO condicionado.

## Interpretación

Club Pádel 04 está preparado para avanzar a contacto comercial con un primer club real como:

- Demo comercial.
- Presentación visual.
- Propuesta piloto.
- Pack fundador.
- Implantación controlada por fases.

## Límite principal

No se debe activar producción real todavía.

## Permitido

Se permite:

- Contactar con un club real.
- Enviar el PDF comercial.
- Enseñar la app visual.
- Realizar una demo guiada.
- Explicar el Pack Fundador.
- Recoger datos básicos.
- Presentar propuesta editable.
- Plantear piloto controlado.
- Resolver objeciones comerciales.
- Preparar siguiente reunión.

## No permitido todavía

No se permite activar:

- Pagos reales.
- Reservas reales.
- Cancelaciones reales.
- Webhooks reales con cliente final.
- WhatsApp Business real.
- Automatizaciones reales conectadas a cliente final.
- Dominio definitivo sin validación.
- DNS definitivo sin revisión.
- Producción comercial operativa sin autorización.

## Condición de venta

La venta debe comunicarse como:

"Fase piloto controlada para validar la solución, adaptar la base del club y preparar una posible producción real posterior."

## Riesgo

Bajo, siempre que se respeten los límites anteriores.

## Veredicto

El proyecto puede enseñarse y venderse como piloto.

No debe venderse todavía como sistema en producción real ya activado.
