# Club Pádel 04 · Frases comerciales recomendadas

## Frase de apertura

Club Pádel 04 no pretende cambiarlo todo de golpe, sino ayudar al club a empezar con más orden, mejor imagen y una base digital preparada para crecer.”

## Para explicar el valor

El valor principal está en centralizar lo que ahora puede estar disperso entre WhatsApp, llamadas, notas, Excel o conversaciones sueltas.”

## Para explicar la primera fase

La primera fase debe ser sencilla, controlada y validada con el club antes de activar nada real.”

## Para explicar el Pack Fundador

El Pack Fundador está pensado para un primer club real de Antequera, con una propuesta más ajustada por ser fase inicial y por permitir validar el sistema en un caso real.”

## Para explicar mantenimiento

El mantenimiento mensual cubre revisión técnica, soporte básico, pequeñas correcciones pactadas, supervisión y acompañamiento.”

## Para explicar límites

Para proteger al club y también el proyecto, es importante definir bien qué entra y qué no entra desde el principio.”

## Para WhatsApp

WhatsApp puede seguir existiendo, pero la idea es que no sea el único sitio donde vive la operativa del club.”

## Para pagos

Los pagos reales deben activarse en una fase posterior, con configuración, validación y pruebas controladas.”

## Para reservas reales

Antes de tocar reservas reales, se haría una validación previa con datos de prueba para evitar errores.”

## Para cerrar reunión

El siguiente paso no es decidirlo todo hoy, sino confirmar si tiene sentido recopilar datos básicos y preparar una propuesta ajustada para una primera fase.”
