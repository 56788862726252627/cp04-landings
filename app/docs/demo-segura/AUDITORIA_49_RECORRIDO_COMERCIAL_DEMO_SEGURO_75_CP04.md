# Club Pádel 04 · Recorrido comercial demo seguro

## Duración

10-15 minutos.

## Objetivo

Mostrar valor sin exponer arquitectura interna ni tocar producción real.

## Recorrido

### 1. Introducción

Explicar que Club Pádel 04 es un sistema inteligente de reservas y gestión para clubes de pádel.

### 2. Problema

Mostrar problemas habituales:

- WhatsApp.
- Llamadas.
- Excel.
- Errores.
- Reservas duplicadas.
- Falta de métricas.

### 3. Vista jugador

Mostrar:

- Reserva demo.
- Mis reservas demo.
- Perfil demo.
- Torneos demo.
- Ranking demo.

### 4. Vista empleado

Mostrar:

- Alta jugador demo.
- Reprogramación demo.
- Cancelación demo.
- Incidencias demo.

### 5. Vista administrador

Mostrar:

- Ocupación demo.
- Reservas demo.
- Jugadores demo.
- Métricas demo.
- Estado demo.

### 6. Automatizaciones

Explicar sin enseñar herramientas internas:

- Confirmaciones.
- Avisos.
- Altas.
- Logs.
- Integración futura con pagos.
- Integración futura con WhatsApp Business.

### 7. Seguridad

Aclarar:

- No hay pagos reales.
- No hay reservas reales.
- No hay cancelaciones reales.
- No se muestran datos sensibles.
- No se exponen herramientas internas.

### 8. Cierre

Preguntar:

- ¿Qué parte os ahorraría más tiempo?
- ¿Qué problema tenéis ahora con las reservas?
- ¿Cuántas pistas y reservas gestionáis?
- ¿Qué necesitaríais para probarlo 60 días?
