# CHECKLIST OPERATIVO · Envío real 5 clubes

## Antes del envío

- [ ] Revisar canal.
- [ ] Confirmar que parece oficial.
- [ ] Confirmar actividad reciente.
- [ ] Elegir mensaje correcto.
- [ ] Copiar mensaje sin errores.
- [ ] Tener abierto registro final.
- [ ] No enviar fuera de horario recomendado.

## Durante el envío

- [ ] Enviar mensaje.
- [ ] Capturar o anotar hora.
- [ ] Registrar canal.
- [ ] Registrar mensaje usado.
- [ ] Marcar contactado como Sí.

## Después del envío

- [ ] No insistir el mismo día.
- [ ] Esperar 48-72 horas.
- [ ] Registrar respuesta.
- [ ] Registrar objeción.
- [ ] Preparar seguimiento si no responde.
