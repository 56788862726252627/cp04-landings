# Club Pádel 04 · Checklist demo rápida para club real

## Objetivo

Realizar una demo comercial clara, breve y segura de Club Pádel 04 sin prometer producción real ni activar funciones sensibles.

## Duración recomendada

10-15 minutos.

## Orden recomendado de demo

1. Presentar la idea general.
2. Enseñar PDF comercial premium.
3. Abrir la app visual.
4. Mostrar pantalla inicial.
5. Mostrar acceso por roles.
6. Mostrar vista jugador.
7. Mostrar reservas.
8. Mostrar torneos.
9. Mostrar ranking.
10. Mostrar staff / recepción.
11. Mostrar administrador.
12. Mostrar soporte técnico.
13. Explicar fases futuras.
14. Explicar Pack Fundador.
15. Resolver dudas.
16. Proponer siguiente paso.

## Frase inicial recomendada

Esto es una demo comercial preparada para enseñar cómo podría funcionar Club Pádel 04 en vuestro club. Todavía no está conectado a reservas reales, pagos reales ni producción definitiva. Antes de eso haríamos una implantación controlada y validada con vosotros.”

## Puntos fuertes que se deben destacar

- Menos gestión manual.
- Menos llamadas y WhatsApp repetitivo.
- Más control de reservas.
- Imagen digital más profesional.
- Acceso por roles.
- Área jugador.
- Staff / recepción.
- Administrador.
- Ranking y torneos.
- Base preparada para automatizaciones futuras.

## Qué no se debe decir

- No decir que ya está listo para producción real.
- No decir que ya cobra pagos reales.
- No decir que WhatsApp Business real ya está conectado.
- No decir que todas las automatizaciones están activas para cliente final.
- No prometer soporte 24/7 salvo que se pacte.
- No prometer cambios ilimitados.
- No prometer integraciones externas sin revisar coste y viabilidad.

## Cierre recomendado de demo

Si os encaja la idea, el siguiente paso sería recopilar los datos básicos del club y preparar una propuesta piloto controlada, con alcance claro y sin tocar reservas reales hasta validarlo todo.”
