# Club Pádel 04 · Checklist final de venta y entrega

## 1. Antes de contactar con el club

- Confirmar nombre del club.
- Confirmar persona de contacto.
- Confirmar canal de contacto.
- Tener preparado el PDF comercial.
- Tener preparado el mensaje de presentación.
- Tener preparada la app visual.
- Tener preparado el guion de demo.
- Tener claro el precio recomendado.
- Tener claro qué incluye y qué no incluye.
- Tener claro que todavía no se activa producción real.

## 2. Material que se puede enviar

- PDF comercial premium.
- Mensaje comercial breve.
- Propuesta inicial.
- Resumen del Pack Fundador.
- Invitación a demo de 10-15 minutos.

## 3. Material que se puede enseñar en reunión

- App visual.
- PDF comercial.
- Roles principales.
- Reservas.
- Torneos.
- Ranking.
- Staff / recepción.
- Administrador.
- Soporte.
- Demo guiada.
- Plan de implantación piloto.

## 4. Datos que se pueden pedir al club

- Nombre del club.
- Número de pistas.
- Horarios.
- Tarifas.
- Tipos de reserva.
- Normas básicas.
- Persona responsable.
- Email.
- Teléfono.
- Logo si existe.
- Colores si existen.
- Necesidades principales.

## 5. Lo que NO se debe activar todavía

- Pagos reales.
- Reservas reales.
- Cancelaciones reales.
- WhatsApp Business real.
- Automatizaciones reales conectadas.
- Escrituras reales en Airtable del cliente.
- Producción comercial definitiva.
- Dominio definitivo.
- DNS definitivo.

## 6. Frase recomendada de seguridad

Ahora mismo te enseño una demo comercial preparada para validar si encaja con vuestro club. Antes de usarla en producción real haríamos una implantación controlada, revisando datos, permisos, pagos y funcionamiento paso a paso.”

## 7. Cierre recomendado

- Preguntar si encaja la idea.
- Resolver dudas.
- Confirmar si quieren una prueba piloto.
- Pedir datos básicos.
- Proponer siguiente reunión.
- No prometer funcionalidades fuera del alcance.
