# Club Pádel 04 · Control de promesas comerciales

## Regla principal

Prometer solo lo que está documentado, preparado y dentro del alcance.

## Se puede prometer

- Demo visual.
- PDF comercial.
- Propuesta piloto.
- App con estructura visual preparada.
- Acceso por roles como concepto funcional.
- Preparación de reservas, jugadores, staff, administrador y soporte.
- Implantación controlada por fases.
- Revisión antes de producción real.
- Mantenimiento básico si se pacta.

## No se debe prometer sin acuerdo específico

- Cambios ilimitados.
- Soporte 24/7.
- WhatsApp Business real.
- Pagos reales.
- Stripe real.
- Integraciones externas.
- Migraciones complejas.
- Hardware.
- Compra de dominio.
- Costes de terceros incluidos.
- Gestión diaria completa del club.
- Campañas continuas.
- Contenido diario.
- Automatizaciones avanzadas no revisadas.

## Frase segura para cambios futuros

Eso se puede valorar como mejora adicional, pero primero conviene cerrar el alcance inicial para no mezclar el piloto con desarrollos más grandes.”

## Frase segura para producción real

Antes de producción real haríamos una validación técnica, revisión de datos, permisos, pagos y autorización expresa del club.”

## Frase segura para precio

El Pack Fundador cubre una primera fase concreta. Cualquier ampliación importante se revisaría aparte para mantener el proyecto controlado.”
