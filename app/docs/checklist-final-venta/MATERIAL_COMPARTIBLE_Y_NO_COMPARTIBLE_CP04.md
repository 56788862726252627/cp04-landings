# Club Pádel 04 · Material compartible y no compartible

## Se puede compartir con un club

- PDF comercial premium.
- Mensaje comercial breve.
- Demo visual de la app.
- Capturas de pantalla seleccionadas.
- Resumen del Pack Fundador.
- Condiciones comerciales resumidas.
- Checklist de datos necesarios.
- Plan de implantación piloto.
- Acuerdo simple de piloto, si el club muestra interés.

## Se puede enseñar, pero no enviar todavía

- Recorrido completo de la app.
- Paneles internos.
- Flujo de demo.
- Propuesta editable.
- Documentación de alcance.
- Mapa maestro de entregables.

## No se debe compartir

- Código fuente.
- Terminal.
- Backups.
- Tokens.
- API keys.
- Blueprints internos completos.
- Webhooks reales.
- URLs internas sensibles.
- Estructura técnica completa.
- Datos reales de pruebas sensibles.
- Documentos de auditoría internos si no son necesarios.

## Regla principal

Compartir solo material comercial y de validación.

La parte técnica interna se mantiene protegida hasta que exista acuerdo claro, autorización y fase de implantación controlada.
