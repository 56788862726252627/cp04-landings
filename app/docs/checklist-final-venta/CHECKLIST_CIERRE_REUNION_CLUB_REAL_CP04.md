# Club Pádel 04 · Checklist cierre de reunión

## Objetivo

Cerrar una reunión comercial dejando claro el siguiente paso sin generar compromisos confusos.

## Preguntas clave al final

- ¿Os encaja la idea general?
- ¿Qué parte os parece más útil para vuestro club?
- ¿Qué problema os gustaría resolver primero?
- ¿Queréis que preparemos una prueba piloto?
- ¿Quién sería la persona responsable para avanzar?
- ¿Qué datos básicos podemos recopilar?
- ¿Preferís avanzar por WhatsApp, email o llamada?

## Siguientes pasos posibles

### Si el club muestra interés alto

- Enviar resumen de reunión.
- Pedir datos básicos.
- Enviar propuesta/acuerdo simple.
- Definir fecha de revisión.
- Preparar piloto controlado.

### Si el club tiene dudas

- Enviar PDF comercial.
- Enviar resumen breve.
- Ofrecer segunda demo.
- Resolver objeciones.
- No presionar.

### Si el club no está interesado

- Agradecer el tiempo.
- Dejar la puerta abierta.
- No insistir demasiado.
- Guardar aprendizaje comercial.

## Frase de cierre recomendada

Perfecto. Para avanzar con seguridad, lo primero sería recopilar datos básicos del club y definir un piloto controlado. Así evitamos tocar reservas reales, pagos o datos sensibles hasta que todo esté revisado y autorizado.”

## Seguimiento recomendado

Enviar mensaje de seguimiento el mismo día o al día siguiente con:

- Agradecimiento.
- Resumen de lo hablado.
- PDF comercial.
- Próximo paso claro.
- Solicitud de datos básicos si procede.
