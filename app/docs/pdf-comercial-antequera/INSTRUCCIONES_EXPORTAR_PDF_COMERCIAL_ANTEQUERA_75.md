# Club Pádel 04 · Instrucciones para exportar PDF comercial

## Archivo HTML preparado

docs/pdf-comercial-antequera/club-padel-04-propuesta-comercial-antequera.html

## Método recomendado

1. Abrir el archivo HTML en Chrome.
2. Pulsar imprimir.
3. Elegir guardar como PDF.
4. Tamaño: A4.
5. Márgenes: predeterminados o ninguno si se ve mejor.
6. Activar gráficos de fondo.
7. Guardar como:

Club-Padel-04-Propuesta-Comercial-Antequera.pdf

## Revisar antes de enviar

- Que no se corten textos.
- Que no haya páginas en blanco extrañas.
- Que el precio se vea claro.
- Que no aparezcan auditorías internas.
- Que no aparezcan detalles técnicos internos.
- Que el documento se vea profesional.
