# Club Pádel 04 · Condiciones recomendadas Pack Fundador Antequera

## Pack recomendado

Club Pro Fundador Antequera.

## Precio

1.490 € implantación inicial.

199 €/mes mantenimiento básico.

## Por qué ofrecer precio fundador

Este precio se recomienda para cerrar el primer club real, obtener validación comercial, generar caso de éxito y construir una referencia local en Antequera.

## Condiciones recomendadas

- Precio válido para el primer club o primeros clubes fundadores.
- Implantación por fases.
- Validación interna antes de activar producción real.
- Cambios pequeños incluidos durante la fase inicial.
- Cambios grandes se presupuestan aparte.
- Costes de terceros no incluidos.
- Pagos reales, WhatsApp Business real y dominio definitivo se activan solo cuando el club lo apruebe.
- Mantenimiento mensual desde la entrega o desde la fecha pactada.
- El club debe facilitar datos básicos para poder adaptar el sistema.

## Qué se debe dejar claro al cliente

- La primera fase busca ordenar y profesionalizar.
- No se promete sustituir todos los procesos del club desde el primer día.
- La app puede crecer por fases.
- Las automatizaciones avanzadas se conectan progresivamente.
- La seguridad y validación son prioritarias.

## Frase comercial recomendada

Este pack fundador está pensado para que seáis de los primeros clubes en tener una base digital propia, con una inversión inicial más baja que el precio estándar posterior.”
