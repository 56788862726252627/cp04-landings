# Club Pádel 04 · Paquete piloto para primer club real

## Objetivo

Preparar una primera implantación piloto de Club Pádel 04 para un club de pádel de Antequera, manteniendo el proyecto seguro, profesional y controlado.

## Enfoque

Club Pádel 04 está diseñado principalmente para un club de pádel de Antequera, con identidad visual inspirada en el Torcal.

Aunque más adelante podrá adaptarse a Archidona, Campillos, Lucena u otros clubes deportivos, esta fase se centra en vender e implantar correctamente el primer caso real en Antequera.

## Qué se entrega en el piloto

- App visual personalizada.
- Acceso por roles.
- Área jugador.
- Área staff / recepción.
- Área administrador.
- Área soporte técnico.
- Reservas visuales.
- Torneos.
- Ranking.
- Perfil de jugador.
- Presentación comercial.
- PDF comercial.
- Guion de demo.
- Acompañamiento inicial.
- Mantenimiento mensual básico.

## Qué se valida antes de conectar datos reales

- Nombre real del club.
- Número de pistas.
- Horarios de apertura.
- Tipos de reservas.
- Duración de reservas.
- Tarifas.
- Roles internos.
- Usuarios responsables.
- Proceso actual de gestión.
- Necesidades prioritarias.
- Qué módulos se activan en fase 1.
- Qué módulos quedan para fases futuras.

## Qué no se activa todavía sin aprobación

- Pagos reales.
- Reservas reales.
- Cancelaciones reales.
- WhatsApp Business real.
- Webhooks reales conectados a datos del cliente.
- Escrituras reales en Airtable del cliente.
- Dominio definitivo del cliente.
- Producción comercial definitiva.
- Automatizaciones críticas sin validación.

## Fase piloto recomendada

### Fase 1

App visual + estructura de roles + reservas simuladas + validación con el club.

### Fase 2

Adaptación de datos reales del club.

### Fase 3

Conexión progresiva de automatizaciones.

### Fase 4

Validación interna con staff.

### Fase 5

Apertura controlada a jugadores.

## Precio recomendado

Pack Club Pro Fundador Antequera:

- 1.490 € implantación inicial.
- 199 €/mes mantenimiento básico.

## Mensaje comercial

El objetivo no es cambiar toda vuestra forma de trabajar de golpe, sino daros una base digital profesional para empezar con más orden, mejor imagen y menos gestión manual.”
