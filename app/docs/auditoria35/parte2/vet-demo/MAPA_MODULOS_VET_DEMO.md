# MAPA DE MÓDULOS · Clínica Veterinaria Demo

## Módulos base

- Inicio
- Citas
- Clientes
- Mascotas
- Servicios
- Veterinarios
- Recordatorios
- Perfil
- Administración
- Automatizaciones
- Soporte

## Módulos recomendados para primera versión

### Inicio

Debe mostrar:

- citas de hoy
- clientes activos
- mascotas activas
- revisiones pendientes
- vacunas próximas
- ingresos estimados
- ocupación por veterinario
- próximos huecos libres

### Citas

Debe permitir:

- crear cita
- seleccionar mascota
- seleccionar servicio
- seleccionar veterinario
- seleccionar fecha y hora
- confirmar
- cancelar
- reprogramar

### Clientes

Debe permitir:

- datos básicos del propietario
- mascotas asociadas
- próximas citas
- recordatorios activos
- preferencias de contacto
- notas internas no clínicas

### Mascotas

Debe incluir:

- nombre
- especie
- raza
- edad aproximada
- propietario
- próximas revisiones
- próximas vacunas
- notas no sensibles

### Servicios

Debe incluir:

- nombre
- duración
- precio
- veterinario compatible
- disponibilidad

### Veterinarios

Debe incluir:

- nombre
- especialidad
- horario
- servicios asociados
- disponibilidad

### Recordatorios

Debe incluir:

- cita próxima
- vacuna próxima
- revisión anual
- desparasitación
- campaña preventiva

### Admin

Debe incluir:

- agenda
- clientes
- mascotas
- servicios
- veterinarios
- recordatorios
- métricas
- automatizaciones
- configuración

## Módulos futuros

## Límites importantes

No incluir en esta fase:

- diagnóstico automático
- recomendaciones veterinarias automáticas
- gestión clínica sensible real
- sustitución del criterio profesional
