# PLAN DE PRODUCTO VENDIBLE · Agencia IA

## Objetivo

Convertir Club Pádel 04 en el primer producto demostrable de la Agencia IA y usarlo como base para crear soluciones SaaS replicables, primero para clubes deportivos y después para negocios locales/profesionales.

---

## 1. Producto base actual

### Nombre actual
Club Pádel 04.

### Tipo de producto
SaaS deportivo para gestión de club de pádel.

### Valor principal
Una plataforma que combina:

- app visual premium
- reservas
- perfiles
- roles
- automatizaciones
- base de datos
- paneles
- soporte
- agentes IA
- flujos Make
- documentación y auditorías

### Estado actual
El producto está en fase de consolidación, con múltiples auditorías realizadas y commits de control.

---

## 2. Producto vendible 1 · SaaS para clubes de pádel

### Cliente ideal
Clubes de pádel pequeños o medianos que necesitan digitalizar reservas, socios, comunicación y procesos internos.

### Problemas que resuelve
- reservas manuales
- pérdida de tiempo en recepción
- falta de control de ocupación
- poca comunicación con socios
- falta de automatizaciones
- ausencia de panel de métricas
- dependencia de WhatsApp/manualidad
- poca imagen tecnológica del club

### Entregables
- app personalizada con marca del club
- sistema de reservas
- perfiles de usuario
- roles staff/admin/soporte
- panel de métricas
- automatizaciones Make
- base de datos Airtable
- emails automáticos
- soporte inicial
- documentación básica
- mantenimiento mensual opcional

---

## 3. Producto vendible 2 · SaaS para clubes deportivos

### Cliente ideal
Centros deportivos que gestionan reservas, clases, socios o instalaciones.

### Sectores incluidos
- tenis
- pádel
- gimnasios
- escuelas deportivas
- academias
- centros de entrenamiento
- centros de yoga/pilates
- clubes municipales

### Adaptación
Se reutiliza la base de Club Pádel 04 cambiando:

- nombre
- colores
- logo
- imágenes
- servicios
- recursos
- lenguaje
- métricas
- automatizaciones

---

## 4. Producto vendible 3 · SaaS para negocios locales

### Cliente ideal
Negocios con citas, clientes, recordatorios, pagos y procesos repetitivos.

### Sectores prioritarios
- clínicas dentales
- fisioterapia
- abogados
- veterinarios
- peluquerías
- estética
- psicología

La reserva pasa a ser cita, consulta, sesión o servicio según sector.

## 5. Servicios de Agencia IA

Además del SaaS, la agencia puede vender servicios complementarios:

- automatizaciones Make
- base de datos Airtable
- agentes IA personalizados
- chatbots
- dashboards
- mantenimiento mensual
- soporte técnico
- auditorías
- integración con pagos
- integración con correo
- integración con WhatsApp futuro
- documentación y formación

---

## 6. Estrategia de venta por fases

### Fase A · Demo principal
Usar Club Pádel 04 como demostración premium.

### Fase B · Primer cliente deportivo
Adaptar el SaaS a un club real o demo clonada.

### Fase C · Plantilla deportiva
Crear una plantilla reutilizable para varios clubes.

### Fase D · Vertical no deportivo simple
Crear versión para peluquería, fisioterapia o veterinario.

### Fase E · Agencia escalable
Convertir cada vertical en paquete vendible.

---

## 7. Regla estratégica

No vender “una app”. Vender un sistema completo:

- app
- automatizaciones
- base de datos
- IA
- soporte
- mantenimiento
- mejora continua
