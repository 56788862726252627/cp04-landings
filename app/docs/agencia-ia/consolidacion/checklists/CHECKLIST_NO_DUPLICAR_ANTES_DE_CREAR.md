# CHECKLIST · No duplicar antes de crear

## Antes de crear cualquier nuevo documento o módulo

- [ ] Revisar si ya existe algo parecido en auditorías 30 a 35.
- [ ] Revisar docs/agencia-ia.
- [ ] Revisar docs/auditoria31, 32, 33, 34 y 35.
- [ ] Confirmar que el nuevo archivo aporta algo nuevo.
- [ ] Confirmar que no es una copia con otro nombre.
- [ ] Confirmar que no se va a tocar código funcional si solo es estrategia.
- [ ] Confirmar que no se duplica App.jsx.
- [ ] Confirmar que no se duplica App.css.
- [ ] Confirmar que no se crean carpetas funcionales innecesarias.
- [ ] Hacer build de seguridad si se está dentro del proyecto.
- [ ] Hacer commit solo de archivos relacionados.

## Regla para nuevos verticales

No crear nuevos verticales hasta haber validado comercialmente al menos:

- 5 clubes deportivos
- 5 fisioterapias
- 5 peluquerías/estética
- 3 veterinarias

## Regla para tocar código

Solo tocar código cuando:

- haya bug real
- haya módulo incompleto prioritario
- haya oportunidad comercial clara
- se haya hecho backup
- se pueda probar con build
- se pueda hacer commit limpio
