# CHECKLIST OBLIGATORIO · No duplicar antes de crear

Antes de crear una carpeta, documento, módulo, prompt, app o flujo nuevo, revisar:

## 1. ¿Existe ya algo parecido?

Comprobar:

- docs/
- docs/auditoria*/
- docs/agencia-ia/
- backups/
- src/
- workflows/
- Make blueprints
- prompts existentes
- commits recientes

## 2. ¿Se puede reutilizar?

Preguntas:

- ¿Este documento ya existe con otro nombre?
- ¿Este módulo ya está implementado parcialmente?
- ¿Este prompt ya se creó antes?
- ¿Esta carpeta ya tiene una versión anterior?
- ¿Este flujo Make ya existe?
- ¿Este concepto puede ampliarse en vez de duplicarse?

## 3. ¿Es específico o reutilizable?

Clasificar:

- Específico de Club Pádel 04.
- Reutilizable para clubes deportivos.
- Reutilizable para cualquier negocio.
- Solo documentación.
- Solo backup.
- Obsoleto o histórico.

## 4. Si hay que crear algo nuevo

Debe cumplir:

- nombre claro
- ubicación correcta
- sin sobrescribir archivos críticos
- backup si afecta a algo existente
- build si toca app
- commit si queda estable
- documento de cierre si es auditoría

## 5. Regla práctica

No crear una nueva versión si se puede:

- ampliar la anterior
- renombrar con sentido
- documentar como sección nueva
- convertir en plantilla
- mover a roadmap futuro
