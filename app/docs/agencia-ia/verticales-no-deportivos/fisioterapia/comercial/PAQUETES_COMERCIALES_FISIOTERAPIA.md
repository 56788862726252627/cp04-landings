# PAQUETES COMERCIALES · Fisioterapia

## Objetivo

Definir paquetes vendibles para clínicas de fisioterapia, centros de rehabilitación y fisioterapeutas con agenda, pacientes, tratamientos, bonos y automatizaciones.

## Paquete 1 · Fisio Starter

### Para quién

Fisioterapeuta autónomo o clínica pequeña que quiere ordenar citas y reducir trabajo manual.

### Incluye

- Agenda/citas básica.
- Pacientes.
- Servicios/tratamientos.
- Emails básicos.
- Configuración inicial.
- Documentación básica.
- 1 ronda de ajustes.

### Precio orientativo

- Setup: 900 € – 1.800 €
- Mantenimiento: 149 € – 249 €/mes

## Paquete 2 · Fisio Pro

### Para quién

Clínica que quiere sistema profesional con citas, pacientes, profesionales, bonos, recordatorios y automatizaciones.

### Incluye

- App personalizada.
- Citas.
- Pacientes.
- Servicios/tratamientos.
- Profesionales.
- Bonos/sesiones.
- Recordatorios.
- Dashboard.
- Automatizaciones Make.
- Base de datos.
- Documentación.
- Soporte mensual.
- 2 rondas de ajustes.

### Precio orientativo

- Setup: 2.000 € – 4.500 €
- Mantenimiento: 299 € – 599 €/mes

### Recomendación

Este es el paquete recomendado para vender primero.

## Paquete 3 · Fisio Premium IA

### Para quién

Clínica que quiere diferenciarse con automatización avanzada, seguimiento, informes y preparación para IA.

### Incluye

- Todo lo de Fisio Pro.
- Seguimiento post-sesión.
- Avisos de bonos bajos.
- Campañas.
- Solicitud de reseñas.
- Informes.
- Preparación para pagos.
- Preparación para WhatsApp.
- Preparación para agentes IA administrativos.
- Soporte prioritario.

### Precio orientativo

- Setup: 5.000 € – 9.000 €
- Mantenimiento: 600 € – 1.500 €/mes

## Límites comerciales

No prometer:

- diagnóstico médico automático
- tratamiento automatizado
- recomendaciones clínicas generadas por IA
- gestión avanzada de datos sanitarios sin revisión legal/técnica

## Estrategia comercial

Empezar vendiendo Fisio Pro porque:

- tiene más valor mensual que peluquería
- se entiende fácil
- resuelve problemas reales
- justifica automatizaciones y mantenimiento
- permite escalar a Premium IA
