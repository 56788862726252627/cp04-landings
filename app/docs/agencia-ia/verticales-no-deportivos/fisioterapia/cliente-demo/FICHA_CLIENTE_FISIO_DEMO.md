# FICHA CLIENTE DEMO · Clínica Fisio Demo

## Objetivo

Crear una ficha conceptual de cliente demo para validar cómo adaptar la base de Club Pádel 04 a una clínica de fisioterapia.

## Datos generales

- Nombre demo: Clínica Fisio Demo
- Sector: fisioterapia
- Tipo de negocio: clínica con citas, pacientes, profesionales y tratamientos
- Ciudad: por definir
- Provincia: por definir
- Nivel de complejidad: medio
- Riesgo legal/sanitario: medio si se gestionan datos clínicos reales
- En esta fase: no se gestionan datos médicos sensibles reales
- Potencial de mantenimiento mensual: alto

## Problemas principales del negocio

- Citas gestionadas por llamadas o WhatsApp.
- Olvidos de pacientes.
- Huecos libres sin ocupar.
- Poco seguimiento después de la sesión.
- Control manual de bonos.
- Falta de recordatorios.
- Agenda poco centralizada.
- Dificultad para medir ocupación por profesional.
- Falta de automatización administrativa.

## Qué se reutiliza de Club Pádel 04

- Login.
- Perfil.
- Roles.
- Dashboard.
- Sistema de reservas transformado en citas.
- Panel administrativo.
- Emails automáticos.
- Automatizaciones Make conceptuales.
- Base de datos conceptual.
- Documentación comercial.
- Checklists.
- Modelo de mantenimiento mensual.
- Estructura de auditorías.
- Sistema de soporte.

## Qué se adapta

- Jugador pasa a Paciente / cliente.
- Pista pasa a Consulta / sala / fisioterapeuta.
- Reserva pasa a Cita.
- Torneo pasa a Programa / taller / campaña.
- Ranking pasa a Evolución / seguimiento.
- Staff pasa a Fisioterapeuta / recepción.
- Club pasa a Clínica / centro.
- Ocupación por pista pasa a Ocupación de agenda.
- Socios activos pasan a Pacientes activos.
- Precio de pista pasa a Precio de sesión / bono.

## Servicios ejemplo

- Valoración inicial.
- Fisioterapia general.
- Fisioterapia deportiva.
- Rehabilitación.
- Masaje terapéutico.
- Readaptación.
- Suelo pélvico.
- Pilates terapéutico.

## Roles recomendados

- Paciente / cliente.
- Fisioterapeuta.
- Recepción.
- Administrador / gerente.
- Soporte técnico.

## Paquete comercial recomendado

Paquete Fisio Pro.

Motivo:

- alto valor operativo
- necesidad real de agenda y recordatorios
- posibilidad de bonos
- mantenimiento mensual más defendible
- escalable a Premium IA

## Precio orientativo

- Setup: 2.000 € – 4.500 €
- Mantenimiento: 299 € – 599 €/mes

## Decisión

Esta ficha sirve como segundo vertical no deportivo y como puente hacia otros negocios profesionales como clínicas dentales, veterinarios o clínicas de fertilidad.
