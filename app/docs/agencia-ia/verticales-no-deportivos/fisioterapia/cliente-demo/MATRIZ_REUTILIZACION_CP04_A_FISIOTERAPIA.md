# MATRIZ DE REUTILIZACIÓN · Club Pádel 04 a Fisioterapia

## Objetivo

Definir qué partes de Club Pádel 04 pueden reutilizarse, adaptarse o deben evitarse al crear un SaaS para fisioterapia.

## Reutilizar directamente

| Elemento Club Pádel 04 | Uso en Fisioterapia |
|---|---|
| Login | Acceso paciente/profesional/admin |
| Perfil | Perfil de paciente |
| Sidebar | Navegación principal |
| Dashboard | Panel de clínica |
| Reservas | Citas |
| Admin | Gestión del centro |
| Soporte | Soporte técnico |
| Emails | Confirmaciones y recordatorios |
| Automatizaciones | Citas, altas, avisos |
| Checklists | Adaptación y entrega |
| Documentación comercial | Base de propuesta |
| Roles | Paciente, profesional, admin, soporte |

## Adaptar

| Elemento actual | Adaptación |
|---|---|
| Jugador | Paciente / cliente |
| Pista | Consulta / sala / fisioterapeuta |
| Reserva | Cita |
| Torneo | Programa / taller / campaña |
| Ranking | Evolución / seguimiento |
| Ocupación por pista | Ocupación de agenda |
| Socios activos | Pacientes activos |
| Club deportivo | Clínica / centro |
| Staff deportivo | Fisioterapeuta / recepción |
| Tarifa pista | Precio sesión / bono |
| Partidos | Sesiones / tratamientos |

## Crear solo si falta

| Elemento | Crear solo si... |
|---|---|
| Módulo de bonos | La clínica vende bonos de sesiones |
| Módulo de seguimiento | Se limita a seguimiento no médico sensible |
| Módulo de profesionales | Hay varios fisios |
| Módulo de tratamientos | Hay servicios diferenciados |
| Módulo de reseñas | Se quiere captar opiniones |
| Agente IA | No diagnostica, solo soporte administrativo/informativo |

## No hacer todavía

- No duplicar App.jsx.
- No duplicar App.css.
- No crear una app nueva.
- No tocar automatizaciones reales.
- No tocar Airtable real.
- No tratar datos médicos sensibles reales.
- No prometer diagnóstico con IA.
- No prometer recomendaciones médicas automáticas.
- No adaptar código hasta cerrar la documentación conceptual.

## Conclusión

La adaptación a fisioterapia es viable y más valiosa comercialmente que peluquería, pero debe mantenerse inicialmente en agenda, citas, bonos, recordatorios y gestión administrativa.
