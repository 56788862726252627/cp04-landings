# MAPA VERTICAL · Fisioterapia

## Objetivo

Adaptar la estrategia SaaS de la Agencia IA a clínicas de fisioterapia, centros de rehabilitación, fisioterapeutas autónomos y centros de salud deportiva.

## Motivo de elección

Fisioterapia es un vertical muy adecuado porque combina:

- citas
- pacientes/clientes
- profesionales
- tratamientos
- sesiones
- bonos
- recordatorios
- seguimiento
- historial básico
- mayor valor mensual que peluquería
- buena relación con el mundo deportivo
- posibilidad futura de IA para soporte, seguimiento y educación del paciente

## Diferencia frente a peluquería

Peluquería valida agenda y servicios simples.  
Fisioterapia añade más valor porque suele necesitar:

- seguimiento por sesiones
- bonos
- evolución del paciente
- recordatorios más importantes
- documentación interna
- mayor confianza profesional
- más margen para mantenimiento mensual

## De Club Pádel 04 a Fisioterapia

| Club Pádel 04 | Fisioterapia |
|---|---|
| Jugador | Paciente / cliente |
| Pista | Consulta / sala / fisioterapeuta |
| Reserva | Cita |
| Torneo | Programa / campaña / taller |
| Ranking | Evolución / seguimiento |
| Staff | Fisioterapeuta / recepción |
| Admin | Director / gerente |
| Soporte técnico | Soporte técnico |
| Ocupación por pista | Ocupación de agenda / sala |
| Socios activos | Pacientes activos |

## Núcleo reutilizable

Se reutiliza:

- login
- perfil
- roles
- dashboard
- reservas transformadas en citas
- panel administrativo
- emails
- automatizaciones
- documentación comercial
- checklists
- modelo de mantenimiento mensual
- estructura de paquetes
- lógica de agenda

## Elementos a adaptar

Se adapta:

- lenguaje deportivo a lenguaje clínico/profesional
- pista por consulta/sala/profesional
- reserva por cita
- ranking por evolución o seguimiento
- torneos por talleres/programas
- tarifas por servicios o bonos
- cliente por paciente, evitando tratar datos médicos sensibles en esta fase
- estilo visual más limpio, sanitario y profesional

- Profesionales

- Perfil

Módulos futuros:

## Importante

En esta fase no se gestionan datos médicos sensibles reales.  
La adaptación es conceptual y comercial.
