# MAPA VERTICAL · Peluquería / Estética

## Objetivo

Adaptar la base estratégica de Club Pádel 04 a un primer vertical no deportivo: peluquerías, barberías y centros de estética.

## Motivo de elección

Este sector es adecuado para la primera adaptación fuera del deporte porque tiene:

- citas
- clientes
- servicios
- profesionales
- horarios
- recordatorios
- promociones
- reseñas
- mantenimiento mensual
- baja complejidad legal comparado con clínicas sanitarias

## De Club Pádel 04 a Peluquería / Estética

| Club Pádel 04 | Peluquería / Estética |
|---|---|
| Jugador | Cliente |
| Pista | Servicio / profesional / cabina |
| Reserva | Cita |
| Torneo | Promoción / campaña |
| Ranking | Historial / fidelización |
| Staff | Profesional / recepción |
| Admin | Dueño / gerente |
| Soporte técnico | Soporte técnico |

## Núcleo reutilizable

Se reutiliza:

- login
- perfil
- roles
- dashboard
- reservas convertidas en citas
- emails automáticos
- base de datos
- automatizaciones Make
- documentación
- checklists
- propuesta comercial
- mantenimiento mensual

## Elementos a adaptar

Se adapta:

- lenguaje deportivo a lenguaje de belleza
- pistas por servicios/profesionales
- torneos por campañas/promociones
- ranking por fidelización
- horarios de pistas por agenda de profesionales
- tarifas deportivas por precios de servicios
- imágenes del Torcal/pádel por estética visual del negocio

## Módulos recomendados

Módulos base:

- Inicio
- Citas
- Clientes
- Servicios
- Profesionales
- Perfil
- Admin
- Automatizaciones
- Soporte

Módulos opcionales:

- Promociones

- Bonos
- Campañas

## Resultado esperado

Crear una primera plantilla conceptual fuera del deporte sin tocar código funcional.
