# DEMO GUIADA · Peluquería / Estética

## Objetivo

Tener un guion para presentar el sistema a una peluquería, barbería o centro de estética.

## Inicio de la demo

Mensaje inicial:

Lo que quiero enseñarte es una base de sistema digital para negocios con citas. La idea es que podáis gestionar agenda, clientes, servicios y recordatorios de forma más ordenada.”

## 1. Pantalla de inicio

Mostrar o explicar:

- citas del día
- clientes activos
- ingresos estimados
- servicios más reservados
- próximos huecos libres

Mensaje:

El objetivo es que al abrir el sistema sepáis qué está pasando hoy en el negocio.”

## 2. Citas

Mostrar o explicar:

- crear cita
- elegir servicio
- elegir profesional
- elegir fecha y hora
- confirmar
- cancelar o reprogramar

Mensaje:

La cita sustituye a la reserva deportiva. Aquí la lógica es muy parecida: fecha, hora, recurso y confirmación.”

## 3. Clientes

Mostrar o explicar:

- datos del cliente
- historial
- preferencias
- notas internas
- próximas citas

Mensaje:

Esto ayuda a no depender solo de WhatsApp o memoria.”

## 4. Servicios

Mostrar o explicar:

- nombre del servicio
- duración
- precio
- profesional compatible

## 5. Automatizaciones

Explicar:

- confirmación de cita
- recordatorio
- cancelación
- seguimiento
- solicitud de reseña
- promociones

## 6. Cierre

Mensaje final:

El objetivo no es vender una web, sino un sistema que os ayude a ahorrar tiempo, ordenar citas y mejorar la experiencia del cliente.”

## Pregunta final

Qué os consume más tiempo ahora mismo: responder mensajes, organizar citas, recordar clientes, llenar huecos libres o hacer seguimiento?”
