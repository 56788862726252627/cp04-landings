# MATRIZ DE REUTILIZACIÓN · Club Pádel 04 a Peluquería / Estética

## Objetivo

Definir qué partes de Club Pádel 04 pueden reutilizarse, adaptarse o deben evitarse al crear un SaaS para peluquería/estética.

## Reutilizar directamente

| Elemento Club Pádel 04 | Uso en Peluquería / Estética |
|---|---|
| Login | Acceso cliente/profesional/admin |
| Perfil | Perfil de cliente |
| Sidebar | Navegación principal |
| Dashboard | Panel de negocio |
| Reservas | Citas |
| Admin | Gestión del negocio |
| Soporte | Soporte técnico |
| Emails | Confirmaciones y recordatorios |
| Automatizaciones | Citas, altas, avisos |
| Checklists | Adaptación y entrega |
| Documentación comercial | Base de propuesta |

## Adaptar

| Elemento actual | Adaptación |
|---|---|
| Jugador | Cliente |
| Pista | Servicio / profesional / cabina |
| Reserva | Cita |
| Torneo | Promoción / campaña |
| Ranking | Historial / fidelización |
| Ocupación por pista | Ocupación de agenda |
| Socios activos | Clientes activos |
| Club deportivo | Negocio local |
| Staff deportivo | Profesional / recepción |
| Tarifa pista | Precio servicio |

## Crear solo si falta

| Elemento | Crear solo si... |
|---|---|
| Módulo de servicios | No existe forma clara de adaptar reservas |
| Módulo de profesionales | El negocio tiene varios trabajadores |
| Módulo de bonos | El cliente vende bonos/sesiones |
| Módulo de campañas | El cliente quiere promociones |
| Módulo de reseñas | Se solicita captación de opiniones |
| Agente IA | Hay caso de uso comercial claro |

## No hacer todavía

- No duplicar App.jsx.
- No duplicar App.css.
- No crear una app nueva.
- No tocar automatizaciones reales.
- No tocar Airtable real.
- No prometer WhatsApp si no está configurado.
- No adaptar código hasta cerrar la documentación conceptual.

## Conclusión

La adaptación a peluquería/estética es viable porque el concepto de reserva puede convertirse en cita y la gestión de pistas puede transformarse en servicios/profesionales.
