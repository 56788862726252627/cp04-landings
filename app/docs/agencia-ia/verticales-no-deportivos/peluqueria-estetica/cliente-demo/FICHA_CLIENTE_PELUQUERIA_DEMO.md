# FICHA CLIENTE DEMO · Peluquería / Estética

## Objetivo

Crear una ficha conceptual de cliente demo para validar cómo adaptar la base de Club Pádel 04 a un negocio local de peluquería o estética.

## Datos generales

- Nombre demo: Peluquería Demo
- Sector: peluquería / estética
- Tipo de negocio: negocio local con citas
- Ciudad: por definir
- Provincia: por definir
- Nivel de complejidad: bajo-medio
- Riesgo legal/sanitario: bajo comparado con clínicas
- Potencial de mantenimiento mensual: alto

## Problemas principales del negocio

- Gestión manual de citas por WhatsApp o llamadas.
- Olvidos de clientes.
- Huecos libres sin ocupar.
- Falta de recordatorios.
- Falta de seguimiento de clientes.
- Poca automatización comercial.
- Agenda poco centralizada.
- Dificultad para promocionar servicios.

## Qué se reutiliza de Club Pádel 04

- Login.
- Perfil.
- Roles.
- Dashboard.
- Sistema de reservas transformado en citas.
- Panel administrativo.
- Emails automáticos.
- Automatizaciones Make conceptuales.
- Base de datos conceptual.
- Documentación comercial.
- Checklists.
- Modelo de mantenimiento mensual.

## Qué se adapta

- Jugador pasa a Cliente.
- Pista pasa a Servicio / Profesional / Cabina.
- Reserva pasa a Cita.
- Torneo pasa a Promoción / Campaña.
- Ranking pasa a Historial / Fidelización.
- Staff pasa a Profesional / Recepción.
- Club pasa a Negocio.
- Ocupación por pista pasa a Ocupación de agenda.
- Socios activos pasan a Clientes activos.

## Servicios ejemplo

- Corte de pelo.
- Corte + barba.
- Color.
- Peinado.
- Manicura.
- Tratamiento facial.
- Depilación.
- Masaje estético.

## Roles recomendados

- Cliente.
- Profesional.
- Recepción.
- Administrador / dueño.
- Soporte técnico.

## Paquete comercial recomendado

Paquete Pro.

Motivo:

- suficiente valor para justificar precio
- no exige demasiada complejidad técnica
- permite mantenimiento mensual
- se puede vender a negocios locales con necesidad clara de agenda y recordatorios

## Precio orientativo

- Setup: 1.500 € – 3.000 €
- Mantenimiento: 199 € – 399 €/mes

## Decisión

Esta ficha sirve como primera prueba conceptual para validar que la Agencia IA puede adaptar la base de Club Pádel 04 fuera del deporte.
