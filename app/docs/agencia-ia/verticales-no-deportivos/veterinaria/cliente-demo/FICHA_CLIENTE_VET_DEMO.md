# FICHA CLIENTE DEMO · Clínica Veterinaria Demo

## Objetivo

Crear una ficha conceptual de cliente demo para validar cómo adaptar la base de Club Pádel 04 a una clínica veterinaria.

## Datos generales

- Nombre demo: Clínica Veterinaria Demo
- Sector: veterinaria
- Tipo de negocio: clínica con citas, clientes, mascotas, servicios y recordatorios
- Ciudad: por definir
- Provincia: por definir
- Nivel de complejidad: medio
- Riesgo legal/sanitario: medio si se gestionan datos clínicos reales
- En esta fase: no se gestionan datos clínicos reales
- Potencial de mantenimiento mensual: alto

## Problemas principales del negocio

- Citas gestionadas por llamadas o WhatsApp.
- Olvidos de vacunas.
- Olvidos de revisiones.
- Dificultad para asociar mascotas a propietarios.
- Huecos libres sin ocupar.
- Falta de recordatorios automáticos.
- Agenda poco centralizada.
- Dificultad para campañas preventivas.
- Falta de seguimiento administrativo.

## Qué se reutiliza de Club Pádel 04

- Login.
- Perfil.
- Roles.
- Dashboard.
- Sistema de reservas transformado en citas.
- Panel administrativo.
- Emails automáticos.
- Automatizaciones Make conceptuales.
- Base de datos conceptual.
- Documentación comercial.
- Checklists.
- Modelo de mantenimiento mensual.
- Sistema de soporte.
- Estructura de auditorías.

## Qué se adapta

- Jugador pasa a Cliente / propietario.
- Perfil de jugador pasa a Perfil cliente + mascota.
- Pista pasa a Consulta / sala / veterinario.
- Reserva pasa a Cita veterinaria.
- Torneo pasa a Campaña preventiva / revisión.
- Ranking pasa a Historial / seguimiento.
- Staff pasa a Veterinario / recepción.
- Club pasa a Clínica veterinaria.
- Ocupación por pista pasa a Ocupación de agenda.
- Socios activos pasan a Clientes y mascotas activas.

## Servicios ejemplo

- Consulta general.
- Vacunación.
- Revisión anual.
- Desparasitación.
- Consulta cachorro.
- Consulta gato.
- Analítica.
- Cirugía menor.
- Peluquería canina, si aplica.

## Roles recomendados

- Cliente / propietario.
- Veterinario.
- Recepción.
- Administrador / gerente.
- Soporte técnico.

## Paquete comercial recomendado

Paquete Vet Pro.

Motivo:

- valor claro
- recordatorios muy vendibles
- revisiones y vacunas recurrentes
- mantenimiento mensual defendible
- menor complejidad que clínica dental o fertilidad

## Precio orientativo

- Setup: 2.000 € – 4.500 €
- Mantenimiento: 299 € – 599 €/mes

## Decisión

Esta ficha sirve como tercer vertical no deportivo y como puente hacia clínicas dentales, fertilidad y otros centros profesionales con citas, clientes y seguimiento.
