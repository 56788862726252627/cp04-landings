# MAPA VERTICAL · Veterinaria

## Objetivo

Adaptar la estrategia SaaS de Agencia IA a clínicas veterinarias, centros veterinarios y consultas para mascotas.

## Motivo de elección

Veterinaria es un vertical muy interesante porque combina:

- citas
- clientes
- mascotas
- revisiones
- vacunas
- recordatorios
- historial básico
- campañas preventivas
- servicios recurrentes
- alta frecuencia de comunicación
- mantenimiento mensual defendible

## De Club Pádel 04 a Veterinaria

| Club Pádel 04 | Veterinaria |
|---|---|
| Jugador | Cliente / propietario |
| Perfil jugador | Perfil cliente + mascota |
| Pista | Consulta / veterinario / sala |
| Reserva | Cita |
| Torneo | Campaña / revisión / plan preventivo |
| Ranking | Historial / seguimiento |
| Staff | Veterinario / recepción |
| Admin | Gerente / dirección |
| Ocupación por pista | Ocupación de agenda |
| Socios activos | Clientes y mascotas activas |

## Núcleo reutilizable

Se reutiliza:

- login
- perfil
- roles
- dashboard
- reservas transformadas en citas
- panel administrativo
- emails automáticos
- automatizaciones
- documentación comercial
- checklists
- modelo de mantenimiento mensual
- estructura de auditorías
- sistema de soporte

## Elementos a adaptar

Se adapta:

- cliente por propietario de mascota
- jugador por mascota/paciente veterinario
- reserva por cita veterinaria
- pista por consulta/veterinario/sala
- ranking por historial o seguimiento
- torneos por campañas preventivas
- tarifas por servicios veterinarios
- recordatorios deportivos por recordatorios de vacunas/revisiones
- estética visual hacia confianza, salud animal y cercanía

## Límites importantes

En esta fase no se gestionan datos clínicos reales de mascotas ni se automatizan diagnósticos.

La adaptación se limita a:

- agenda
- citas
- clientes
- mascotas
- servicios
- recordatorios
- campañas
- automatizaciones administrativas
