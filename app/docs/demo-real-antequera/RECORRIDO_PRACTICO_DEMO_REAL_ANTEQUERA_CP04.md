## Qué decir

# 17. Precio

## Qué mostrar

Página de planes recomendados.

## Qué decir

Para una primera implantación, el pack recomendado es Club Pro Fundador Antequera: 1.490 € + 199 €/mes.”

Es una forma de empezar con una base profesional, validar el sistema con el club y no entrar directamente en una implantación demasiado grande.”

# 18. Mantenimiento

## Qué mostrar

Mantenimiento mensual.

## Qué decir

El mantenimiento cubre revisión técnica, soporte básico, incidencias menores, pequeños ajustes pactados, supervisión y acompañamiento mensual.”

## Aclarar

Cambios ilimitados, integraciones externas grandes, pagos reales, WhatsApp Business real o soporte 24/7 se pactarían aparte.”

# 19. Cierre

## Qué decir

Mi recomendación sería hacer una demo de 10-15 minutos, resolver dudas, confirmar el pack más adecuado y recopilar los datos básicos del club para preparar una implantación controlada.”

Agendar demo comercial y revisar pack fundador.
