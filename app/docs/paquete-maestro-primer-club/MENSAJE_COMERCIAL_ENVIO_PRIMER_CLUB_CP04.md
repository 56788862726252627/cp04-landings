## Mensaje más formal para email

Asunto: Propuesta digital para gestión y reservas de club de pádel

Hola,

Soy Eduardo Rodríguez y estoy preparando Club Pádel 04, una propuesta de sistema inteligente de reservas y gestión para clubes de pádel.

El objetivo es ayudar a un club a centralizar reservas, jugadores, staff, administración, torneos, ranking, soporte y futuras automatizaciones en una experiencia digital profesional.

La propuesta está pensada inicialmente para un club de pádel de Antequera, con identidad visual inspirada en el Torcal y una primera fase controlada para validar el sistema antes de activar cualquier producción real.

Adjunto el PDF comercial para que podáis ver el enfoque.

Si os parece interesante, podemos agendar una demo breve de 10-15 minutos para enseñaros la app visual, resolver dudas y valorar si tendría sentido hacer un piloto.

Gracias.

Un saludo,  
Eduardo Rodríguez
