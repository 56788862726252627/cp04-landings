# Club Pádel 04 · Matriz de decisión del primer club

## Si el club responde con interés alto

Acción recomendada:

- Proponer demo de 10-15 minutos.
- Preparar app visual.
- Preparar propuesta editable.
- Recoger datos básicos.
- No activar producción real todavía.

## Si el club responde con interés medio

Acción recomendada:

- Enviar PDF comercial.
- Enviar resumen breve.
- Preguntar qué parte le interesa más.
- Ofrecer demo sin compromiso.

## Si el club responde con dudas

Acción recomendada:

- Resolver dudas.
- Explicar que puede empezar por una fase sencilla.
- No presionar.
- Ofrecer demo visual.

## Si el club dice que ya gestiona por WhatsApp

Respuesta recomendada:

La idea no es eliminar todo de golpe, sino reducir carga repetitiva y ordenar la gestión para que el club tenga más control y mejor imagen digital.

## Si el club dice que no necesita algo tan avanzado

Respuesta recomendada:

Se puede empezar con una primera fase sencilla: app visual, reservas, roles y organización básica. Después se añaden automatizaciones solo si son necesarias.

## Si el club pregunta si ya funciona

Respuesta recomendada:

La base visual y funcional está preparada para demo. Antes de usarlo en producción real se haría una implantación controlada, validada con el club, sin tocar reservas reales hasta confirmar todo.

## Si el club pregunta por cambios

Respuesta recomendada:

El sistema está pensado por fases. Primero se define lo básico y después se pactan mejoras concretas.

## Si el club quiere empezar

Acción recomendada:

- Confirmar alcance.
- Confirmar precio.
- Confirmar datos necesarios.
- Preparar acuerdo simple.
- Validar antes de activar nada real.
