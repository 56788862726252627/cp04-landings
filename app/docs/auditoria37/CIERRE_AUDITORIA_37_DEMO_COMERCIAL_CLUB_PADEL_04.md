## Decisión estratégica

Tras cerrar Auditoría 36, se decidió que el foco comercial principal debe volver a Club Pádel 04 como producto base.

Motivo:

- es el producto más avanzado
- ya existe app
- ya existe identidad visual
- ya hay propuesta comercial
- ya hay material de demo
- permite validar con clubes deportivos reales
- es la base para replicar después a otros sectores

## Qué se puede enseñar

En una demo comercial se puede enseñar:

- pantalla inicial
- identidad visual
- roles
- reservas
- perfil
- panel administrador
- automatizaciones conceptuales
- propuesta de valor
- mantenimiento mensual

## Qué no se debe prometer todavía

No prometer:

- pagos reales si no están integrados
- WhatsApp real si no está configurado
- cancelaciones reales sin entorno validado
- integración definitiva con Make/Airtable sin revisión previa
- IA avanzada terminada
- cambios ilimitados
- módulos incompletos como si estuvieran cerrados

## Regla de demo

La demo debe explicarse como una base avanzada y personalizable, no como producto final cerrado al 100%.

Frase recomendada:

Esta demo sirve para validar el flujo principal y ver si resuelve vuestro problema. Las integraciones reales se activan por fases.”
