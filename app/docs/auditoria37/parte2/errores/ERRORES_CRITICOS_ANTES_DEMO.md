# ERRORES CRÍTICOS ANTES DE DEMO

## Errores que bloquean demo

- Pantalla negra.
- App no carga.
- Error visible de React/Vite.
- Menú principal inutilizable.
- Botones principales ilegibles.
- Textos esenciales cortados.
- Sidebar bloquea toda la app.
- Rutas principales rotas.
- Credenciales o tokens visibles.
- Datos privados visibles.
- Marcas de terceros visibles.
- Flujo de reserva imposible de explicar.

## Errores que no bloquean si se explican bien

- Algún módulo futuro no terminado.
- Alguna automatización aún conceptual.
- Pagos no activos.
- WhatsApp no activo.
- Alguna métrica pendiente.
- Algunas vistas pendientes de integración real.

## Regla

Si aparece un error bloqueante, no se enseña la demo a cliente hasta resolverlo.

Si aparece un error no bloqueante, se puede enseñar siempre que se explique que está en fase demo y no se prometa como funcional final.
