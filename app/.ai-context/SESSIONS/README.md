# Sessions

Un archivo por sesión de trabajo material, nombrado `AAAAMMDD-herramienta-resumen.md`
(p. ej. `20260826-claude-code-context-hub.md`), usando la plantilla de
`../templates/session-summary.md`.

No crear una entrada por cada mensaje o pregunta trivial: solo cuando se
haya producido un cambio real (código, documentación, decisión, bloqueo
identificado) que valga la pena que otra herramienta/sesión pueda leer
después sin tener que preguntárselo de nuevo al usuario.
