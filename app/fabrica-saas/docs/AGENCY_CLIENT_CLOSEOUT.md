# Client Project Closeout

## Statuses
| Status | Meaning |
|--------|---------|
| CLOSED | All conditions met, project archived |
| CLOSED_WITH_DEFERRED_ITEMS | Closed with some Fase 2 items documented |
| BLOCKED | Cannot close — resolve blocks first |

## Blocking Conditions
1. Delivery manifest not generated
2. Handoff not complete (acceptance checklist or training checklist)
3. Critical components not DONE (landing, app, modules, qa, security, documentation)
4. Support window not defined
5. Critical open Change Requests (BUG / SCOPE_CHANGE / NEW_REQUIREMENT) in non-final status

## Deferred Items (non-blocking)
- Change Requests with status DEFERRED
- Future improvements listed in delivery manifest
