# Support SOP

## Ticket Priority and Response Time
| Priority | Description | Response |
|----------|------------|---------|
| P1_CRITICAL | System down, data loss | 1 hour |
| P2_HIGH | Major feature broken | 4 hours |
| P3_MEDIUM | Minor issue, workaround exists | 24 hours |
| P4_LOW | Cosmetic, question | 72 hours |

## Ticket Types
- BUG → covered in support window
- CONFIGURATION → covered
- TRAINING_QUESTION → covered
- SCOPE_CHANGE → NOT covered, requires CR
- NEW_FEATURE → NOT covered, requires CR

## Escalation
- P1_CRITICAL → PROJECT_MANAGER immediately
- Repeated P1 → AGENCY_OWNER
