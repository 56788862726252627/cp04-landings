# Client SOP — Full Lifecycle

## Stages
1. Lead Intake → Commercial captures and validates
2. Qualification → Budget, timeline, decision maker, sector
3. Discovery → Pain points, current tools, goals
4. Diagnosis → Root causes, recommendations
5. Requirements → P0/P1/P2 classification
6. Proposal Review → Client reviews, decides
7. Approval → Agency owner authorizes
8. (Change Requests handled at any stage)
9. Delivery Acceptance → Client reviews against delivery manifest
10. Handoff → Training + acceptance checklists
11. Support Start → Tier-based window opens
12. Closeout → Declarative close record

## Key Policies
- Qualification: budget < 500 EUR → NOT_A_FIT
- Health data → HUMAN_REVIEW always
- Change Request types: BUG, MINOR, ADDON, SCOPE_CHANGE, URGENT, NEW_REQUIREMENT
- Support covers: BUG, CONFIGURATION, TRAINING_QUESTION only
- Closeout disclaimer: "REGISTRO DECLARATIVO DE CIERRE. NO ES UN CONTRATO LEGAL."
