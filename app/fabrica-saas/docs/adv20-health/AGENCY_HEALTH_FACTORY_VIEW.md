# ADV-20 — Factory Health View Reference

## Purpose

The Factory Health View exposes the health of the SaaS factory infrastructure itself — build pipeline, test suite, security posture, CI/CD, deployment readiness, observability, client isolation, and production readiness.

## Factory Score (0-100)

Computed from 8 boolean flags × 12.5 points each:

| Flag | Points |
|------|--------|
| securityHealthy | 12.5 |
| testsHealthy | 12.5 |
| cicdHealthy | 12.5 |
| buildHealthy | 12.5 |
| deploymentHealthy | 12.5 |
| observabilityHealthy | 12.5 |
| clientIsolationHealthy | 12.5 |
| productionReadyHealthy | 12.5 |

A perfect factory score = 100.

## Scope Boundary

The factory view covers only the factory/agency infrastructure. It does NOT include CP04, Bot Trading, Aurora, FisioNova, EducaArchidona, or any production client environment. `noCP04: true` is enforced on every factory view output.

## Generated SaaS Profile

SaaS products generated by the factory inherit the health framework via `createGeneratedSaaSHealthProfile`. Each generated SaaS can declare its own health signals but uses the same aggregation, priority rules, and quality gate.

## Usage

```js
import { createFactoryHealthView } from './health/dashboard/factoryHealthView.js';

const view = createFactoryHealthView({
  securityHealthy: true,
  testsHealthy: true,
  cicdHealthy: true,
  buildHealthy: true,
  deploymentHealthy: false,
  observabilityHealthy: true,
  clientIsolationHealthy: true,
  productionReadyHealthy: false,
});
// view.factoryScore = 75
// view.noCP04 = true
```
