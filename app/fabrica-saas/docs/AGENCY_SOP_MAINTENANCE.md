# Maintenance SOP

## Review Areas
| Area | Critical if Fail |
|------|-----------------|
| Security patches | YES (CRITICAL) |
| Backup verification | NO (WARNING) |
| Dependencies | NO (WARNING) |
| Performance | NO (WARNING) |
| Integration health | YES (CRITICAL) |
| Automation health | NO (WARNING) |
| AI health | NO (WARNING) |
| Client change review | NO |
| Documentation | NO |

## Status
- HEALTHY: no criticals, no warnings
- WARNING: warnings only
- CRITICAL: any critical issue

## Disclaimer
"Maintenance report only. No changes applied automatically."
