# Commercial SOP

## Pipeline
1. Recommend package (ESSENTIAL/PRO/PREMIUM)
2. Calculate pricing
3. Identify addons
4. Calculate third-party costs
5. Generate estimate
6. Build proposal
7. Agency owner review (if discount > 15%)
8. Human review (if flagged)
9. Send proposal
10. Proposal review call
11. Client decision (accept/negotiate/reject)
12. Revise if needed (max 2 rounds)

## Pricing Reference
| Package | Setup | Monthly |
|---------|-------|---------|
| ESSENTIAL | 1200 EUR | 89 EUR |
| PRO | 2400 EUR | 149 EUR |
| PREMIUM | 4500+ EUR | 249 EUR |

- COMMERCIAL_GATE: budgetQualified + decisionMakerConfirmed
