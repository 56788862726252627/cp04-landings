# Scope Management

## Scope Categories
- **includedScope** — delivered in this engagement
- **excludedScope** — explicitly NOT included
- **optionalScope** — available as add-ons (P2 requirements)
- **deferredScope** — Fase 2 (P3 requirements)

## Anti-Scope-Creep Rules
1. All new functionality requires a formal Change Request.
2. Design changes approved after production start — Change Request MINOR.
3. Additional modules beyond package limit — add-on or package upgrade.

## Client vs Agency Responsibilities

### Client
- Content (texts, images, logo)
- Third-party account creation (Supabase, Make, domain)
- Validation sessions (2-4h/week)
- Acceptance testing

### Agency
- Design, development, Make automations, Cloudflare deployment
- QA before delivery
- Basic documentation
- Post-delivery support per plan
