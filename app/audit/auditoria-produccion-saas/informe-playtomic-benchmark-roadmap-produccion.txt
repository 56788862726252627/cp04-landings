9. SEGURIDAD PENDIENTE PARA PRODUCCIÓN REAL
─────────────────────────────────────────────────────────────
  BACKEND (no implementable en frontend):
  ⚠ Autenticación real con JWT o session cookies httpOnly/Secure
  ⚠ Rate limiting en endpoints de login y forgot-password
  ⚠ CSRF tokens en formularios
  ⚠ Bcrypt/argon2 para contraseñas (nunca en texto plano)
  ⚠ Validación server-side de todos los inputs
  ⚠ Logs de auditoría sin datos sensibles (no logear passwords)
  ⚠ CORS restrictivo en worker/API
  ⚠ RGPD: consentimiento explícito y política de privacidad real
  ⚠ HTTPS obligatorio en producción
  ⚠ Backups cifrados de datos

  FRONTEND (pendiente):
  ⚠ Content Security Policy (CSP) en headers
  ⚠ Expiración de sesión local con logout automático
  ⚠ Subresource Integrity (SRI) para fuentes externas
  ⚠ Eliminar contraseñas demo del código antes de producción real

  ⬜ Endpoint: POST /api/auth/forgot-password { email }
     → Buscar usuario en DB, generar token con expiración (15-30min)
     → Enviar email con enlace: /reset-password?token=xxx
  ⬜ Endpoint: POST /api/auth/reset-password { token, newPassword }
     → Validar token, verificar expiración, hashear y guardar password
  ⬜ Pantalla /reset-password en la app con form de nueva contraseña
