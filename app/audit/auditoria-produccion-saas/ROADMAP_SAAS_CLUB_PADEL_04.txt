─────────────────────────────────────────────────────────────
SISTEMA DE PUNTOS — NOTA
─────────────────────────────────────────────────────────────
El sistema de puntos actual es configurable por el club.
No se afirma que sea oficial de la FAP (Federación de Pádel)
ni de ninguna federación, salvo que el usuario aporte la
fórmula exacta y sea correctamente implementada.

Estructura preparada para adaptar cualquier normativa federada.
Documentación: "Sistema de puntos configurable del club."

─────────────────────────────────────────────────────────────
ARQUITECTURA TÉCNICA RECOMENDADA
─────────────────────────────────────────────────────────────
Frontend:   React 19 + Vite (actual)
Auth:       Supabase Auth / Auth.js / Clerk
DB:         Supabase (PostgreSQL) / PlanetScale
Backend:    Cloudflare Workers (actual para reservas) + Next.js API
Pagos:      Stripe (preparado)
Email:      Resend o SendGrid
Storage:    Cloudflare R2 / Supabase Storage
Deploy:     Cloudflare Pages / Vercel
Monitoring: Sentry / Cloudflare Analytics
