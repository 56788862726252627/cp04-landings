# 04_landing/src — Implementación

**Uso**: aquí vive el código de la landing una vez cerrado el diseño en Figma (`04_landing/figma/`) y el copy (`04_landing/copy/LANDING_COPY_TEMPLATE.md`).

No se genera código de plantilla genérico aquí — el código real se implementa con Claude Code cuando el negocio concreto lo necesite, reutilizando componentes del núcleo documentado en `docs/agencia-ia/ARCHITECTURE_CORE_VS_VERTICAL.md` cuando aplique, y adaptando estilos al `03_identidad_visual/BRAND_SYSTEM_TEMPLATE.md` de este negocio.

No copiar código de `club-padel-04` directamente a un negocio de otro sector sin pasar antes por la adaptación visual — evita que la landing "se note" como una copia.
