# 04_landing/assets — Recursos visuales

**Uso**: logo del negocio, fotografías reales, iconos exportados de Figma e imágenes de banco gratuito seleccionadas para este negocio.

- Guardar solo assets ya decididos (los descartados no se suben aquí, para no confundir en la implementación).
- Nombrar archivos de forma descriptiva y en minúsculas con guiones (`logo-principal.svg`, `hero-local-exterior.jpg`), nunca `imagen1.jpg` o similar.
- Confirmar que cualquier foto de personas (clientes, pacientes, equipo) tiene permiso de uso antes de subirla aquí.
