# 01 — Investigación

**Uso**: carpeta libre (sin plantilla fija) para notas de investigación del sector y la competencia local, a partir de lo recogido en `00_brief_inicial/BRIEF_NUEVO_NEGOCIO.md`.

Cada sector es distinto, por eso no hay un formulario cerrado aquí. Como mínimo, documentar:

- 2-3 competidores directos locales (o del sector, si no hay competencia local directa) y cómo comunican/qué precios tienen.
- Qué buscan realmente los clientes de este sector cuando contratan (no solo lo que el negocio cree que vende).
- Qué nivel de digitalización tiene el sector en la zona (¿ya usan software de reservas/citas o todo es manual?).
- Referencias visuales de 2-3 negocios del sector que transmitan bien la imagen que se busca (para alimentar `03_identidad_visual/`).

Guardar aquí cualquier nota, enlace o captura relevante. No requiere formato fijo — pasar a `02_oferta_y_posicionamiento/` cuando haya suficiente contexto para definir la oferta.
