## 1. Datos operativos a recoger

- Listado real de servicios/horarios/precios a cargar en el sistema.
- Personal que usará el sistema (nombres, roles: dueño/recepción/profesional).
- Logo en alta calidad y colores finales confirmados (si no se recogieron ya en `03_identidad_visual/`).
- Dominio/subdominio a usar para la landing/app.
- Datos de contacto oficiales (teléfono, email, dirección) para la landing.

## 2. Configuración técnica

- [ ] Carpeta del proyecto creada en `projects/<slug-del-negocio>/` a partir de esta plantilla.
- [ ] Identidad visual (`03_identidad_visual/`) cerrada y aplicada.
- [ ] Landing (`04_landing/`) publicada en entorno de preview.
- [ ] Datos operativos cargados (servicios, horarios, precios).
- [ ] Roles y accesos del personal creados.
- [ ] Referencia al núcleo técnico (`docs/agencia-ia/ARCHITECTURE_CORE_VS_VERTICAL.md`) revisada para confirmar qué módulos aplican a este sector.

## 3. Formación al cliente

- [ ] Sesión de formación agendada con el responsable del negocio.
- [ ] Formación cubre: cómo se ven las reservas/citas, cómo gestionar cambios, a quién contactar en caso de duda/incidencia.
- [ ] Material de apoyo entregado (guía corta en PDF o documento, no dar por hecho que recordarán todo de la sesión oral).

## 4. Confirmación de arranque

- [ ] Cliente confirma por escrito que el sistema está operativo y correcto.
- [ ] Fecha de "puesta en producción" registrada.
- [ ] Traspaso a `11_entrega_soporte/SOPORTE_TEMPLATE.md` para el mantenimiento continuo.
