# 02 — Oferta y Posicionamiento

**Uso**: carpeta libre (sin plantilla fija) para definir, a partir del brief y la investigación, qué se vende exactamente y cómo se diferencia de la competencia local.

Como mínimo, documentar antes de pasar a `03_identidad_visual/`:

- Qué paquete de `docs/agencia-ia/comercial/PRICING_MAESTRO_AGENCIA_IA_CLUB_PADEL_04.md` encaja mejor con este negocio (diagnóstico solo / automatización básica / automatización Pro / SaaS completo).
- Una frase de posicionamiento (qué nos diferencia de que el negocio siga a mano o contrate otro software genérico).
- Los 3 beneficios principales que se van a repetir en toda la landing y la propuesta (deben coincidir con `04_landing/copy/LANDING_COPY_TEMPLATE.md` y `08_propuesta/PROPUESTA_TEMPLATE.md`).

No requiere formato fijo — es la bisagra entre la investigación y el trabajo visual/comercial que viene después.
